================================================================
v61 — [개념검증] 채널 드롭아웃 증강으로 전극 고장 강건성 하드닝 (base 1개)
       PoC 성공: clean 보존(−0.38p), 전극 1개 고장 저하 −12.9p→−1.3p
================================================================


[1] 계기
v60에서 전극 1개 고장 = −13.5p(앙상블) 취약성 발견. 훈련 중 무작위로 전극을
0으로 만드는 채널 드롭아웃 증강으로 특정 전극 과의존을 없애면 고장에 강건해질
것. base 1개로 개념검증(성공 시 앙상블로 확대).


[2] 방법 (깔끔한 A/B)
  baseline = v40 (v8 아키텍처 + v40 레시피, 채널드롭 없음) = 기존 best_model_v40
  v61      = v8 + v40 레시피 + 채널드롭 증강(전극별 독립 드롭 q=0.10, 평균 ~1.2개)
  차이는 오직 채널드롭. 데이터 full-RAM + 샘플별 transpose(빠름·OOM 없음), 50ep.
  검증: clean 정확도 보존 여부 + 전극 고장(1/2/3개) 저하가 baseline보다 작아지나.


[3] 결과 (프레임 acc)
  조건       v40 base   v61 chdrop   개선
  ────────   ────────   ──────────   ──────
  clean      70.05%     69.66%       −0.38p
  전극 1개   57.15%     68.33%       +11.18p
  전극 2개   51.32%     66.06%       +14.75p
  전극 3개   47.95%     63.54%       +15.59p
  (v61 clean 동작단위 85.97% / hard 59.54% — v40와 동급)


[4] 해석 (PoC 성공)
  · clean −0.38p → 사실상 보존(무시할 비용).
  · 전극 1개 고장 시: v40는 clean 대비 −12.9p 급락, v61은 −1.3p만 하락.
    → 채널드롭 증강이 전극 과의존을 제거, 고장에 강건.
  · 2/3개 고장에서도 +14~16p 우위. v60의 앙상블 취약점(−13.5p)을 정면 해소.


[5] 문제
학습 후 평가 코드 버그(per_movement 반환값 언팩) → 모델은 정상 저장됨.
eval_v61.py로 평가만 분리 재실행해 해결(재학습 불필요).


[6] 배운 점
  · 채널 드롭아웃 증강 = 전극 고장 강건성의 저비용 해법(clean −0.4p로 −11p+ 방어).
  · 증강은 "라벨 의미 보존"(v43 교훈) 조건을 만족 — 전극을 끄는 것은 "그 전극이
    없는 같은 동작"이라 라벨 불변. (전극 shift가 실패한 것과 대조.)


[7] 다음
  PoC 성공 → 앙상블 전 멤버(또는 핵심 멤버)를 채널드롭 증강으로 재훈련하면
  배포 모델 전체가 전극 고장에 강건해짐. 단 화요일 마감·재훈련 비용 고려해
  범위(전 멤버 vs 대표 1~2개) 판단 필요.

  python code/eval_v61.py        # 평가(clean + 전극고장 곡선), ~4분
  결과: results/v61/result_v61.json

  저비용(clean −0.38p)으로 확보. 앙상블 확대 검토.
