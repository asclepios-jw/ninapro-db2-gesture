================================================================
v54 — 스펙트로그램 2D-CNN 앙상블 멤버: 프레임 천장 못 넘음
       다른 아키텍처는 선택되나(비상관) 너무 약해(57%) 이득 ≈ 0
================================================================


[1] 계기
v51~v53에서 정직한 성능 계층(프레임 73% → 실제분할 80% → oracle 88%)이 전부
기저 프레임 모델(73%)에 묶임을 확인. 프레임 앙상블은 같은 계열(v8/특징/Residual)
로 73.00%에서 포화. 근본적으로 다른 아키텍처(2D 시간-주파수 CNN)로 비상관
다양성을 넣어 프레임 천장을 넘을 수 있는지 시도.


[2] 방법
  - models_v54.SpectrogramCNN: 24ch 시간영역 → 채널별 STFT(n_fft=64,hop=16) →
    로그-크기 스펙트로그램(24,33,38) → 2D-CNN(Conv2d×3+GAP) + subject emb → FC.
    파라미터 109K(경량). 입력·출력공간은 기존 멤버와 동일(drop-in).
  - 학습: v40 파이프라인(강한 증강 + focal, 50ep). 증강은 시간영역 x에 적용 후
    모델 내부 STFT → 일관.
  - 평가: 10-후보(기존 9 + v54) 앙상블 전수 sweep(추론만).


[3] 기대
스펙트로그램은 1D-CNN-LSTM과 완전히 다른 귀납편향 → 비상관 오류 → 단독이
약해도(v47 교훈) 앙상블 프레임을 73% 위로 밀 것.


[4] 결과
  v54 단독: acc 57.13% / macroF1 0.3392 / hard 44.4% (best epoch 19, 15.9분)
    → 1D 계열(70%대)보다 13p 낮음. 스펙트로그램이 이 신호·설정에서 단독으론 약함.

  10-후보 앙상블 sweep:
    최고 조합(9개, v54 포함): 72.9983% / hard 62.97% / macroF1 0.6438
    v48(9후보, v54 없음) 72.9955% 대비: +0.003p (순수 노이즈)
    v54는 최고 조합에 '포함됨'(v44_rep2 대신 v54+v45_r1) → 비상관 다양성은 있음.
    그러나 net 이득 0 → 프레임 천장 73.00% 그대로.

  크기별: 7개에선 v54 포함이 소폭 유리(72.97%), 전체 풀에선 씻겨나감.


[5] 문제
없음. 스모크로 STFT shape·forward·OOM 사전 검증. 학습·sweep 정상.
v54가 약한 이유 추정: (a) STFT 파라미터(64/16)·경량 2D-CNN이 최적 아님,
(b) 300ms 윈도우가 스펙트럼 해상도에 빡빡, (c) 정규화된 신호의 스펙트럼이
1D 시간 패턴보다 정보량 적음.


[6] 배운 점
**"약해도 비상관이면 앙상블에 기여"에는 하한이 있다.**
  v47에서 v41(70%)·v38(69.5%)은 앙상블을 밀었다(개별 −0.5p 수준). 그러나
  v54(57%)는 13p나 약해서, 비상관이라 선택은 되지만 낮은 개별 정확도가
  확률 평균을 끌어내려 net 이득이 0에 수렴.
  → 앙상블 멤버는 '비상관 + 충분히 강함(풀 평균에서 크게 뒤지지 않음)' 둘 다
    필요. 다양성만으로는 부족.

**프레임 천장 73.00%는 견고하다.**
  같은 계열 포화 + 다른 아키텍처(약한) 추가로도 안 넘음. 이 천장을 넘으려면
  '다른 아키텍처면서 동시에 강한(~70%)' 멤버가 필요 — 스펙트로그램을 제대로
  키우거나(ResNet+log-mel 등), 다른 전처리/입력.

**하위 계층(80%/88%)도 프레임에 묶여 불변.**
  프레임이 안 오르니 v52 평활·v53 분할·oracle 전부 그대로.


[7] 다음 (남은 옵션)
1. 스펙트로그램 모델 강화(더 큰 2D-CNN, log-mel, 윈도우↑) → 단독 65%+ 되면
   앙상블 기여 가능. 불확실.
2. 다른 전처리(10Hz) 멤버 — 단 라벨 미비 블로커(PLAN-3 경로A).
3. 프레임 천장(73%)을 인정하고, 정직한 배포 계층(v51~v53)과 효율곡선으로
   마무리(PLAN-2/5). ← 현실적.
