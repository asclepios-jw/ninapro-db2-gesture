================================================================
v38 — v36(증강+focal) 장기 학습 100ep: 69.48%
       pooled 상한 +0.23p, gap 역대 최소(11.21p)
================================================================


[1] 이 모델/설정을 선택한 계기 — 결정의 맥락

v36(69.25%)이 50ep을 조기 종료 없이 완주했고 ep49에서 best val_f1을
갱신하며 마지막까지 상승 중이었다 = 아직 수렴 전.

가설: 에포크를 늘리면 pooled base의 상한이 올라간다.
      더 좋은 base를 만든 뒤 다시 fine-tuning(v39)을 얹으면 70% 돌파 가능.

v37(69.83%)은 v36 base에 fine-tuning을 얹은 결과였으므로,
v38로 base 자체를 끌어올리면 그 위의 fine-tuning도 함께 올라갈 것으로 기대.


[2] 전 버전(v36)과 달라진 점

장기 학습을 위한 세 값만 함께 조정 (반드시 동반 조정):
  N_EPOCHS         50 → 100
  CosineLR T_max   50 → 100   ← 스케줄 동반 조정. 안 바꾸면 50ep 이후
                                LR이 eta_min에 붙어 학습이 멈춤.
  PATIENCE          8 → 15    ← 100ep 기준 더 느린 수렴 허용

나머지 완전 동일: v28 전처리, v8 arch, 증강(jitter/magwarp/timewarp/mixup),
                 Focal Loss(γ=2), AdamW 1e-3, batch=256.


[3] 변경 이유 + 기대했던 효과

증강이 과적합을 없앴기 때문에(v36에서 tr<val 확인) 모델은 더 오래
학습할수록 계속 개선될 여지가 있었다. CosineAnnealing을 100ep에 맞게
다시 펼치면 후반부에 LR이 천천히 낮아지며 미세 조정이 이어진다.

기대: +0.2~0.4p → 69.4~69.6% (pooled).
     이후 v39 fine-tuning으로 70% 시도.


[4] 기대와 실제가 어떻게 달랐는가

기대: +0.2~0.4p
실제: **+0.23p** (v36 69.25% → v38 69.48%) — 기대 범위 하단 달성.

  overall : 69.48%  (v36 대비 +0.23p)
  hard acc: 59.66%  (v36 58.71% 대비 +0.95p — pooled 라인 역대 최고)
  easy acc: 70.87%  (v36 70.75% 대비 +0.12p)
  macro-F1: 0.5926  (v36 0.5874 대비 +0.0052)
  gap     : 11.21p  (v36 12.04p 대비 축소 — 메인 pooled 라인 역대 최소)

주목: 에포크 증가의 이득이 hard subject에 집중됐다(+0.95p vs easy +0.12p).
     v36에서 이미 확인된 "증강은 hard를 돕는다"가 장기 학습에서 더 강화.
     gap이 11.21p로 줄어든 것도 hard 개선이 주도.


[5] 학습 중 예상치 못하게 발생한 문제들

기술적 문제: 없음.

가장 중요한 관찰 — best epoch = 100 (마지막 에포크):
  val_f1이 100ep 끝까지 미세하게 상승. 조기 종료 미발동.
  그러나 상승 기울기는 급격히 완만해짐:
    ep50 val_f1=0.6158 → ep70=0.6262 → ep100=0.6310
    후반 30ep(70→100) 동안 +0.0048에 불과 → 사실상 완만한 천장 접근.
  즉 "아직 오르지만 거의 눕는 중". 150ep로 늘려도 이득은 미미할 것.

  tr_acc는 ep100에서 0.6765 — 여전히 val(0.7133)보다 낮음.
  증강 덕에 과적합은 끝까지 없었다(장기 학습이 안전했던 이유).


[6] 이번 버전에서 배운 점

**장기 학습은 확실히 이득이지만 시간 대비 효율이 낮다.**

  v38: 230분(3.8시간) 학습 → +0.23p.
  v37: 29분 fine-tuning → +0.58p.
  같은 시간을 fine-tuning에 쓰는 게 훨씬 효율적.
  → 장기 학습은 "마지막 상한을 짜낼 때"만 쓸 카드.

**증강+장기 학습의 이득은 hard subject에 집중된다.**
  pooled hard acc: v32 57.84% → v36 58.71% → v38 59.66%.
  증강이 만든 다양성을 오래 학습할수록 hard가 더 흡수.
  gap도 12.40p → 12.04p → 11.21p로 꾸준히 축소.

**과적합이 없으면 장기 학습이 안전하다.**
  일반 모델이라면 100ep에서 과적합으로 val이 꺾였겠지만,
  증강으로 tr<val 상태라 끝까지 안정적으로 상승.
  → 증강과 장기 학습은 상호 보완적(증강이 장기 학습을 가능케 함).


[7] 다음 버전에서 고쳐볼 점 + 기대 효과

1. **(v39, 즉시) v38 체크포인트 기반 adaptive fine-tuning (v37 방식)**
   v38(69.48%) base 위에 per-subject fine-tuning + val_f1 선택.
   v37에서 v36 base(+0.58p)를 얹었던 것과 동일.
   base가 v36보다 0.23p 높으므로 유사 이득 시 **70.0~70.1% 기대**.
   비용: ~29분. 최우선.

2. **(보류) 더 긴 학습 (150ep)**
   v38이 ep100까지 미세 상승했으나 기울기가 거의 누움.
   150ep는 +0.05~0.1p 수준으로 예상 → 시간 대비 비효율. 보류 권장.

3. **(v40, 단기) 증강 강도 튜닝**
   hard가 장기 학습에 잘 반응 → 증강을 강화하면 hard 추가 개선 가능.
   magwarp σ 0.20→0.30, timewarp σ 0.15→0.25, mixup α 0.20→0.30.
   v38 장기 학습 설정과 결합. 기대: +0.1~0.3p (또는 최적점 탐색).

4. **(중기, 2안) 아키텍처 업그레이드 + 동일 증강+장기학습**
   증강이 hard/일반화에 효과적임을 반복 확인.
   더 강한 아키텍처(multi-scale conv, Transformer, residual CNN)에
   증강+focal+장기학습+adaptive 전체 파이프라인 적용.
   과거 v23/v24 multi-scale 실패는 증강 없이 시도했기 때문 → 재도전 가치.
   기대: +0.5~1.5p (분산 큼).
