v60 — [안정화 4/4, 밀렸던 S4] 강건성 테스트
       잡음엔 강건, 전극 고장·게인엔 취약 (한계로 문서화)

[1] 계기
안정화 우선순위에서 밀렸던 S4(강건성)를 마저 수행. champion이 실사용 교란
(잡음·전극 고장·게인 드리프트)에 어떻게 저하되는지 정량화. 재학습 0, 추론만.


[2] 방법
champion 8모델 상주, test 4만 윈도우 부분표본. 교란을 추론 입력에 적용:
  · 잡음: 가우시안 σ(신호std 대비) {0.05,0.1,0.2,0.4}
  · 전극 고장: k개 전극=0 (raw i + envelope i+12 쌍), k{1,2,3}, 3회 무작위 평균
  · 게인: 전체 배수 g {0.5,0.7,1.5,2.0}


[3] 결과 (기준 프레임 73.07% / hard 63.79%, 부분표본)
  잡음 σ:   0.05 −0.08p / 0.1 −0.12p / 0.2 −0.48p / 0.4 −3.40p
  전극고장 k: 1 −13.53p / 2 −20.46p / 3 −24.63p
  게인 g:   0.7 −7.39p / 1.5 −10.03p / 0.5 −19.68p / 2.0 −23.03p
  (부분표본 기준 73.07%가 전체 73.0%와 일치 → 표본 대표성 확인)


[4] 해석
  · ✅ 잡음 강건: σ0.2까지 −0.5p 이내. 훈련의 jitter 증강(σ0.06)이 효과.
  · ❌ 전극 고장이 최대 취약점: 1개만 죽어도 −13.5p. 실사용에서 전극 이탈·
    고장은 흔함 → 진짜 배포 리스크. 원인: 24채널 전부를 신뢰하도록 학습,
    채널 드롭 증강 미적용.
  · ⚠️ 게인 민감: 단 "정규화 후 갑작스런 드리프트"의 worst-case. 세션별
    재정규화로 지속적 게인은 흡수됨(전처리에 정규화 존재). 전극 고장이 더 본질.


[5] 문제
없음(추론 599s). 주의: 게인 교란은 정규화 이후 적용 → 지속적 게인이 아닌
급변만 반영. 전극 고장은 재정규화로도 복구 불가(채널 사망).


[6] 배운 점 / 한계 (문서화 대상)
  · 강점: 부가 잡음에 강건.
  · 한계1(중요): 전극 1개 고장 시 −13.5p — 배포 시 전극 신뢰성·재장착 절차
    또는 채널 드롭 증강 재훈련 필요.
  · 한계2: 급격한 게인 드리프트에 민감 — 세션별 재정규화로 완화 권장.
  이는 개발 동결 상태이므로 "알려진 한계 + 후속 과제"로 보고서에 기록.


[7] 다음
  후속 과제(개발 재개 시): 채널 드롭아웃 증강 + 게인 증강으로 재훈련하면
  전극 고장·게인 강건성 개선 예상. 지금은 문서화만.
  → 안정화 분석(v57~v60) 종료. 남은 것 = 문서 최종화.
