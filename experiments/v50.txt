================================================================
v50 — 클래스 균형 샘플러로 macro-F1 향상 시도: 실패
       재균형은 macro-F1도 낮췄다 — 상한은 판별력(신호)에 있다
================================================================


[1] 이 버전을 시작한 계기

v49 진단: 낮은 macro-F1의 원인 = 12개 제스처가 rest로 새는 낮은 recall,
         rest가 train의 44%로 지배. 처방: 학습 단계에서 rest 완화 →
         제스처 recall↑ → macro-F1↑ 기대. (v49 후처리 보정은 무효였음)


[2] 전 버전(v45)과 달라진 점

유일한 변경: train 샘플러.
  v45: 자연 분포 (rest 44%)
  v50: WeightedRandomSampler(sqrt 역빈도) → rest 유효비중 44%→11.3%
  아키텍처(TD+FD)·증강·손실(focal γ2) 동일. (v3~v6 교훈: focal에 강한
  class weight 겹치면 폭락 → 샘플러 하나만, 온건한 sqrt로)
평가에 rest_recall / gesture_recall 추가.


[3] 변경 이유 + 기대했던 효과

rest 지배를 줄이면 모델이 제스처 윈도우를 상대적으로 더 학습 → rest로
새던 제스처 recall이 올라 macro-F1 개선 기대. acc는 소폭 하락 감수.


[4] 기대와 실제가 어떻게 달랐는가

기대: 제스처 recall↑ → macro-F1↑ (acc 소폭↓)
실제: **acc·macro-F1 둘 다 하락.** 재균형이 역효과.

  v45  acc 70.31%  macroF1 0.6002  (균형 없음)
  v50  acc 64.35%  macroF1 0.5681  (sqrt 균형)
  변화: acc −5.96p  macroF1 −0.0321
  rest recall 0.721  gesture recall 0.592  (best epoch 36)

**왜 macro-F1까지 떨어졌나:**
  rest를 11.3%로 과하게 줄이자 모델이 rest 경계에 대한 보정을 잃고
  제스처를 과예측 → rest 윈도우에 오탐(false positive) 급증 → 제스처
  precision 붕괴 → 제스처 F1↓ → macro-F1↓. (acc는 rest가 test의 44%라
  rest 오분류로 크게 하락.)
  = v49 후처리(τ↑ 시 macroF1 단조 하락)와 정확히 같은 메커니즘, 학습판.


[5] 학습 중 예상치 못하게 발생한 문제들

문제 없음. 샘플러 유효비중 사전 검증(44%→11.3%), 학습 정상 완주(101.8분,
best ep36). 결과가 나쁜 것이지 실행 이상은 아님.


[6] 이번 버전에서 배운 점

**macro-F1의 낮음은 '재균형으로 고칠 편향'이 아니라 '판별력(신호) 상한'이다.**
  후처리(v49)·학습측 재균형(v50) 두 방향 모두 실패, 같은 메커니즘.
  → 예측을 제스처 쪽으로 미는 어떤 방법도 macro-F1을 못 올린다.
    저F1 12개 제스처가 rest로 새는 건 '경계/약활성 윈도우가 실제로
    rest처럼 보이는' 신호 자체의 모호성. 재균형은 오탐만 늘린다.

**두 번의 정합적 음성 결과 = 강한 결론.**
  v49(후처리 τ*=0)와 v50(sqrt 재균형 −0.032)이 서로 다른 축에서 같은
  방향을 가리킴 → macro-F1 재균형 라인은 종료. milder power를 시도해도
  최적점이 '재균형 없음(v45)'이므로 이득 없음(덜 나쁠 뿐).

**막다른 길 목록 추가:** macro-F1 재균형(후처리+학습).
  장기학습·용량확대·hard라벨·전극shift에 이어.


[7] 다음 — macro-F1을 정말 올리려면 (남은 옵션, 모두 불확실/고비용)

재균형이 아니라 '판별력'을 높여야 한다:
  1. 헷갈리는 제스처 쌍을 더 잘 구분하는 정보/특징 (현재 특징으로는 rest와
     겹침). 어떤 제스처가 rest와 겹치는지 세부 분석 후 표적 특징.
  2. 윈도우/purity 재설계 — 경계(onset/offset) 윈도우를 rest로 라벨하거나
     제외. 데이터 파이프라인 변경, 영향 범위 큼.
  3. 상한 인정 — macro-F1 0.64(앙상블)는 이 신호·윈도우 설정의 현실적 한계에
     가까움. acc 73%가 강한 결과이므로 여기서 정리하는 것도 합리적.

권고: 재균형 라인은 종료. macro-F1 추가 개선은 근본적으로 다른 접근이
     필요하며 성공 불확실. 현재 최고(앙상블 73.00%/0.6444)는 유지.

[9] 비용 원장

  학습: 101.8분 (pooled). 성능 순손실(acc −5.96p, macroF1 −0.032).
  이득: 0(성능). 단 "macro-F1 상한은 판별력"이라는 결론 확정.


[결론]

  macro-F1은 재균형(후처리 v49 + 학습 v50)으로 개선 불가 — 판별력/신호 상한.
  현재 최고: 앙상블 v48 = 73.00% / macro-F1 0.6444 (유지).
  전체 여정 v25(62.58%) → v48(73.00%): +10.42p.
