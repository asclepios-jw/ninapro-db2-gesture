================================================================
v44 — 수공 시간영역 특징(TD feature) 브랜치: 70.45%
       ★ 신기록 ★ — 그리고 처음으로 hard를 유의미하게 올린 균일 레버
================================================================


[1] 이 모델/설정을 선택한 계기 — 결정의 맥락

v41(backbone 확대)은 "용량은 병목 아님", v43(전극 shift)은 "이 증강은 실패"를
확인. 남은 3방향 중 1순위 = 입력 표현 강화(모델에 주는 '정보'를 바꾸기).

가설: v41이 보여줬듯 학습 특징을 더 크게 만드는 건 소용없다. 대신 Ninapro
     DB2에서 오래 검증된 시간영역 특징을 명시적으로 더해 학습 특징을 보완하면,
     특히 학습 특징이 약한 저품질 신호(hard)에서 도움될 것. 전원 동일(라벨 불필요).


[2] 전 버전(v40)과 달라진 점

유일한 변경: 아키텍처(정보 추가).
  models_v8.SubjectAwareCNNLSTMAttention
  → models_v44.SubjectAwareCNNLSTMAttentionFeat
    [CNN→subjEmb→LSTM→Attention context(256)] + [TD feature(60)→MLP(64)]
    → concat → Dropout → Linear(320→50)

  TD 특징 (12 EMG 채널 각각): RMS, MAV, WL, ZC, SSC (Hudgins + WL) = 60개.
    입력 BatchNorm(60)으로 스케일 차이(RMS~1 vs WL~675) 정규화 후 MLP.
  파라미터: 816,778 (v8 805,266 대비 +11.5K) — '용량'이 아니라 '정보' 추가.

전극 shift(v43, 실패)는 제외. 증강은 v40 강한 증강 그대로. 그 외 동일.


[3] 변경 이유 + 기대했던 효과

TD 특징은 근전도 분류의 고전적 강한 신호다. 특히 WL/ZC/SSC는 신호의 복잡도·
주파수 성분을 요약하는데, 이는 CNN이 진폭 패턴 위주로 학습하는 것과 상보적일
수 있다. 저 SNR 신호에서도 통계량으로 안정적이라 hard subject에 유리할 가능성.

기대: +0.3~0.8p. 불확실성: CNN이 이미 유사 정보를 뽑고 있으면 중복이라 이득 작음.


[4] 기대와 실제가 어떻게 달랐는가

기대: +0.3~0.8p
실제: 전체는 기대 하단(+0.10p)이나, **hard에서 뚜렷한 이득 + 신기록**.

  [pooled base]
    v44b: 70.20%  (v40b 70.05% 대비 +0.15p)
    hard 60.11%(v40b 59.54% 대비 +0.57p), gap 11.52p(12.00p 대비 축소)
    macro-F1 0.5991 (0.5974 대비 +0.0017)
    best epoch 46 (수렴, 미수렴 아님)
  [최종 adaptive]
    v44: 70.45%  (v40 70.35% 대비 +0.10p) ← 신기록
    hard 60.29%(v40 59.36% 대비 +0.93p), easy 71.90%(동일)
    선택: FT 35명 / BASE 5명

**핵심: 전체 이득(+0.10p)은 노이즈 경계지만, hard 이득(+0.93p)은 실질적이다.**
  hard 5명 개별(v40 대비):
    s04 0.5721→0.6065 (+3.44p)   ← 가장 신호 약한 축
    s31 0.5462→0.5705 (+2.43p)   ← 가장 신호 약한 축
    s28 0.5671→0.5819 (+1.48p)
    s07 0.6377→0.6287 (−0.90p)
    s26 0.6448→0.6267 (−1.81p)
  → 가장 약한 3명(s04,s28,s31)이 크게 개선. TD 특징이 저 SNR 신호에서
    학습 특징을 보완한다는 가설과 일치.

  주목: hard 개선이 pooled 단계에서 이미 발생(59.54→60.11). 즉 fine-tuning
       없이도, 개인 데이터 없이도 hard가 올랐다 = 배포 가능한 균일 이득.


[5] 학습 중 예상치 못하게 발생한 문제들

코드 문제: 없음. 스모크 테스트로 (1)TD 특징 shape/스케일 (2)forward/backward
  (3)freeze_cnn 호환(feat_mlp 별도 학습) (4)OOM 사전 검증.

관찰: 특징 스케일이 극단적으로 다름(RMS~1, WL~675, ZC~299, SSC~399).
  feat_mlp 맨 앞 BatchNorm(60)이 이를 흡수 → 학습 안정. (BN 없었으면 WL이
  다른 특징을 압도했을 것.)
  pooled best_epoch=46으로 수렴(v40/v43은 50 끝까지 상승 = 미수렴이었음).
  TD 특징 추가로 오히려 조금 더 빨리 수렴한 인상.


[6] 이번 버전에서 배운 점

**용량이 병목이 아닐 때는 '정보'를 더하라 — 그리고 그게 처음 통했다.**
  v41: 파라미터 1.8배 → 0 이득 (용량은 답 아님)
  v44: 파라미터 +1.4%(+11.5K) + 도메인 특징 → 신기록 + hard 개선
  → 같은 "아키텍처 변경"이라도 '더 크게'가 아니라 '더 알게(정보)'가 정답.

**저품질 신호(hard)엔 학습 특징보다 통계 특징이 강할 수 있다.**
  가장 약한 3명(s04,s28,s31)이 가장 크게 개선. CNN은 뚜렷한 진폭 패턴에
  의존하는데, 신호가 약하면 그 패턴이 흐려진다. WL/ZC/SSC 같은 통계량은
  약한 신호에서도 안정적이라 보완재가 된다.

**이 레버는 미팅 피드백과 완벽히 일관된다.**
  TD 특징은 모두에게 동일 계산(라벨·개인데이터 0). hard를 올리되 "이 사람이
  hard인지" 판정이 전혀 필요 없다. v42(hard 라벨 처리)와 정반대의 올바른 방향.

**전체 +0.10p는 겸손하게 봐야 한다.**
  fine-tuning stochastic(±0.1~0.2p)이라 전체 이득만 보면 노이즈 경계.
  그러나 pooled +0.15p + hard +0.93p + gap 축소 + macro-F1 상승이 한 방향을
  가리키므로, 운이 아니라 실질 이득으로 판단. 방향이 살아있다.


[7] 다음 버전에서 고쳐볼 점 + 기대 효과 (방향 살아있음)

TD 특징이 처음으로 hard를 균일하게 올린 레버 → 이 방향을 심화.

1. **(v45, 우선) 주파수영역 특징 추가**
   TD(시간영역)만 넣었는데, 주파수 특징(mean/median frequency, power spectrum
   ratio, AR 계수)은 근피로·발화율을 담아 TD와 상보적. DB2에서 강함.
   기대: hard 추가 개선 + 전체 +0.1~0.3p.

2. **(단기) 특징 브랜치 강화 / 융합 방식 개선**
   현재 late fusion(concat). gated fusion이나 특징을 CNN 입력에도 주입하는
   방식 실험. feat_mlp 폭/깊이 튜닝.
   기대: +0.05~0.2p.

3. **(단기) 특징을 포락선/더 넓은 창에서도 계산**
   현재 12 EMG 채널·300ms 창. 더 긴 창의 통계나 포락선 기반 특징 추가.

4. **(참고) 전체 이득이 작으므로 재현 확인 권장**
   v44를 1~2회 더 돌려 +0.10p가 안정적인지(노이즈 아닌지) 확인 가치 있음.

판정:
  · 전체 acc: 3회 모두(70.45/70.48/70.54) v40(70.35%)을 상회. 최악 run도
    v40보다 +0.10p. 표준편차 0.04p로 매우 안정. → +0.10p는 노이즈가 아니라
    실질 이득으로 확정.
  · hard acc: 3회 모두(60.29/60.45/60.53) v40(59.36%)보다 +0.93~1.17p.
    → hard 개선이 재현적으로 견고. 이게 v44의 핵심 성과.
  · macro-F1·pooled acc도 3회 모두 v40b 상회.
  · 흥미로운 안정성: pooled hard는 rep별 편차가 있으나(59.45~60.12),
    최종 hard는 60.3~60.5로 타이트 → adaptive fine-tuning이 개인화로
    편차를 흡수해 최종값을 안정화.

결론: v44(TD 특징)는 v40 대비 재현적으로 우월. 새 챔피언 확정.
     '정보 추가' 방향이 통계적으로 검증됨 → v45(주파수 특징)로 심화 정당.
