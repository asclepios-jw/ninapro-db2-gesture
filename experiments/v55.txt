================================================================
v55 — 학습된 시간 보정(temporal corrector): 부분 성공
       프레임은 악화, per-movement 정확도·hard는 손튜닝 초과 (macroF1은 열세)
================================================================


[1] 계기 (도전적 베팅)
v51~53: 프레임(73%)↔oracle(88%) 15p가 시간 구조에 잠김. 손튜닝(평활/분할)으로
80%까지 회수. 그러나 모델이 시간 구조를 '학습'한 적은 없음(윈도우 독립 분류).
→ 손튜닝을 학습으로 대체하면 더 뽑을 수 있는가? 데이터가 직접 가리킨 방향에 베팅.


[2] 방법
2차 시퀀스 모델(경량 LSTM)을 앙상블 확률 스트림 위에 학습:
  - 입력: log(앙상블 8모델 확률) 피험자 시간순 시퀀스.
  - 타깃: 참 라벨 시퀀스. per-timestep CE. 청크(256, stride128) 학습.
  - 학습셋 = val(rep5, 준-out-of-fold), 테스트 = rep6.
  - 두 모드: bidir(오프라인, 미래 문맥) / causal(단방향, 실시간).


[3] 기대
손튜닝 평활/분할이 하던 걸 모델이 배워 → 프레임/스트리밍을 80%대로,
per-movement를 oracle(88%) 쪽으로 밀 것.


[4] 결과 — 기대와 엇갈림

  방식              프레임 acc      per-movement acc  hard(PM)  macroF1(PM)
  ────────────────  ─────────────   ────────────────  ────────  ───────────
  앙상블 기준       73.00%          —                 —         —
  bidir(오프라인)   71.86% (−1.13p) 82.58%            79.8%     0.7195
  causal(실시간)    68.17% (−4.83p) 77.98%            70.2%     0.6079
  (참조 손튜닝)     중심78.6/분할80.4                 73.4      0.78(분할)
  (참조 oracle)     —               88.04%            83.9      0.85

핵심:
  1. 프레임 레벨에서 학습 코렉터는 오히려 악화(−1.1~−4.8p). 손튜닝 중심평활
     (78.6%)에 크게 못 미침. LSTM이 구간 지배 라벨로 과평활 → 전이·짧은
     제스처에서 프레임 정확도 손실.
  2. per-movement에서 bidir 82.58% — 손튜닝 실제분할(80.44%)을 +2.14p 초과,
     hard 79.8%로 손튜닝(73.4%)을 +6.4p 크게 초과(oracle 83.9%에 근접).
     → 학습이 hard의 시간 구조를 더 잘 잡음.
  3. 그러나 macroF1(0.72)은 손튜닝(0.78)보다 낮음 — 흔한 클래스로 쏠림.
     정확도·hard는 얻고 희귀 클래스는 잃는 트레이드오프.
  4. 어느 것도 oracle 88%엔 못 미침.


[5] 문제
없음(정상 실행, 190s). 약한 겹침: rep5가 멤버 체크포인트 선택에 쓰여 학습셋이
완전 out-of-fold는 아님 → 수치는 약간 낙관적일 수 있음(참고 caveat).


[6] 배운 점
**학습된 시간 보정은 손튜닝을 '깔끔히' 이기지 못했다 — 베팅은 절반만 적중.**
  - 프레임/스트리밍: 손튜닝(평활)이 학습보다 우수. 학습 코렉터는 과평활.
  - per-movement 정확도·hard: 학습이 우세(특히 hard +6.4p). 시간 구조 학습이
    어려운 피험자에서 값어치.
  - macroF1: 학습이 열세. 정확도-macroF1 트레이드오프 재확인.

**왜 기대만큼 안 됐나:**
  (a) 학습셋이 rep5 1개(≈1960 인스턴스)로 작음 → 코렉터가 과/과소적합.
  (b) 입력이 확률(50-d)뿐 → 원신호 특징 없이 교정 정보 제한.
  (c) LSTM이 정확도↑엔 유리하나 희귀 클래스 recall엔 불리(과평활).

**결론적 위치:** 손튜닝 후처리(v52/v53)가 이미 강해서, 학습으로의 전환은
  hard·per-movement 정확도에서만 소폭 우위. 판을 바꾸진 못함.


[7] 다음 (도전 계속 or 정리)
1. (코렉터 강화, 불확실) 학습셋을 rep1-4 교차검증 out-of-fold로 확대 +
   입력에 원신호 특징(TD/FD) 추가 + causal에 제한적 lookahead. 성공 시
   프레임/스트리밍도 학습이 이길 여지. 단 첫 시도가 미온적이라 기대 조정.
2. (정리) 손튜닝 계층(v52/v53)이 정직한 배포 최선임을 확정하고, 학습
   코렉터는 "hard per-movement 보조"로만 기록. 보고/문서화로 전환.

권고: 프레임을 못 넘은 게 핵심 실망. 코렉터 강화(1)는 upside가 좁아졌으므로,
     한 번 더 판을 바꿀 다른 도전(예: 자기지도 사전학습)이 아니면 정리(2)가 합리적.
