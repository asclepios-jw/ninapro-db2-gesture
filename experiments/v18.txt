================================================================
v18 — DANN: 피험자 불변 특징 학습 시도, 전 지표 악화
================================================================

[이 버전을 시작한 계기]

v12~v17의 핵심 발견은 "어려운 피험자는 신호 자체가 약하고 동작 간 분리도가
낮다"는 것이었다. v14~v17의 계층적 분류 계열이 4개 버전에 걸쳐 v8을 넘지
못하고 수익체감 패턴을 보이자, 근본적으로 다른 방향을 시도하기로 했다.

DANN(Domain Adversarial Neural Network, Ganin et al. 2016)은 도메인 적응의
표준 기법으로, "피험자마다 신호 분포가 다르다"는 피험자 간 변동성을 직접
공략한다 — 피험자(=도메인)를 예측할 수 없는 특징을 학습하도록 강제함으로써,
어느 피험자의 신호가 들어와도 동작 구분이 잘 되는 범용 특징을 학습시키는 것이
목표였다.


[방법: code/models_v18.py, code/train_cnn_v18.py]

기존 v8 아키텍처(SubjectAwareCNNLSTMAttention)에서 가장 큰 변화는 subject
embedding(32차원) 제거다 — 모델이 피험자 정보를 쓰지 못하도록 입력 자체에서
차단했다. 전체 구조는 세 부분으로 나뉜다:

1) Feature extractor: Conv1d(24→64→128) + BatchNorm + ReLU → BiLSTM(128,
   layers=2, bidirectional) → attention pooling → 256차원 특징 벡터.
   v8과 동일한 구조이나 subject embedding 없음.

2) Label head: Dropout(0.4) + Linear(256 → 50). 동작 분류 담당.

3) Domain head: GRL(alpha) → Linear(256→128) → ReLU → Dropout(0.3) →
   Linear(128→40). 피험자 예측 담당.

핵심 메커니즘: Gradient Reversal Layer(GRL)는 순전파에서는 항등함수지만,
역전파에서 gradient를 -alpha배로 뒤집는다. 이로 인해:
  - Domain head는 피험자를 잘 맞히도록 학습되지만
  - Feature extractor는 피험자 예측이 안 되는 방향으로 학습된다
  (Label head의 gradient는 그대로 → 동작 구분 유지)

alpha 스케줄: Ganin et al.의 p 기반 스케줄 사용.
  alpha(p) = 2 / (1 + exp(-10*p)) - 1,  p = epoch / n_epochs
  epoch 1에서 alpha≈0(적대 신호 없음)으로 시작해 epoch 30에서 alpha≈1.0으로
  수렴 — 초반에 기본 제스처 분류를 먼저 학습한 뒤 적대 학습을 점진적으로 강화.

학습 레시피: AdamW(lr=1e-3, wd=1e-4), CosineAnnealingLR(T_max=30),
30 epochs, patience=6, val macro-F1 기준 체크포인트.
총 손실 = CE(gesture, label_smoothing=0.1) + 1.0 × CE(domain).

[기대와 실제가 어떻게 달랐는가]

기대: 피험자 불변 특징을 학습하면 어려운 피험자에게 더 공정한 특징이 추출되어
hard-easy 격차가 줄고, 전체 정확도도 v8에 근접하거나 넘어설 수 있다고 기대했다.

실제: 전체 정확도가 59.10%로 v8(68.69%)보다 9.6p 낮았고, gap도 13.28p로
v8(12.77p)보다 오히려 더 벌어졌다. 모든 지표에서 v8보다 나쁜 명확한 음성 결과다.

원인 분석:

1. subject embedding 제거가 핵심 손해 — v8에서 subject embedding은 "이 신호가
   피험자 X의 것"이라는 정보를 모델에 직접 제공해 피험자별 적응을 가능하게
   했다. 이를 제거하자 모델이 피험자 간 신호 차이를 활용할 수 없어 분류
   정확도가 크게 떨어졌다.

2. EMG는 본질적으로 피험자-의존적 — DANN은 "도메인 차이를 없애면 범용성이
   높아진다"는 가정 위에 서 있는데, EMG에서는 피험자별 근육 신호 특성이
   동작 구분에 중요한 정보이기도 하다. 피험자 구분 불가능한 특징은 동시에
   동작 구분력도 낮은 특징일 수 있다.

3. hard subject의 진짜 문제는 "분포 차이"가 아니라 "신호 품질" — v12에서
   확인한 것처럼 어려운 피험자의 낮은 정확도는 피험자 간 분포 불일치가 아니라
   신호 자체의 낮은 separability에서 온다. DANN이 해결하려는 "도메인 불일치"와
   v12에서 진단한 "신호 품질" 문제는 다른 문제였다. 진단과 처방이 맞지 않았다.


[학습 중 예상치 못하게 발생한 문제들 — 버전/환경/하드웨어]

1. Docker 공유 메모리(shm) 부족 — 첫 실행 시 DataLoader worker 프로세스 간
   공유 메모리가 Docker 기본값(64MB)을 초과해 RuntimeError 발생.
   setup_container.sh에서 --shm-size=4g를 주어 해결.

2. CUDA OOM (batch_size=512) — BiLSTM이 600 타임스텝 시퀀스를 처리할 때
   두 경로(gesture + domain)를 동시에 backprop하면서 메모리가 부족.
   batch_size 512→256으로 줄여서 해결. val/test loader도 1024→256으로 감소.
   부작용으로 학습 시간이 v8의 3배로 늘어남.

3. Docker 볼륨 권한 문제 — Docker가 root로 실행되어 마운트 경로에 생성되는
   파일/폴더가 root 소유가 됨. tee로 로그 저장 시 "Permission denied" 발생.
   전용 컨테이너(ninapro-dev, sleep infinity)를 만들어 docker exec로 실행하는
   방식으로 전환해 해결.


[v1~v18 전체를 관통하는 결론]

v18은 v9~v11, v13과 마찬가지로 "가설 자체가 데이터에 맞지 않았다"는 음성
결과다. DANN의 전제("피험자 불변 특징이 범용성을 높인다")는 이미지 분류나
텍스트 분류에서는 잘 통하지만, EMG 분류에서는 피험자 정보 자체가 분류에
유용한 특징이기 때문에 제거하면 득보다 실이 크다.

v12의 진단("hard subject = 신호 품질 문제")을 다시 돌아보면, 이 문제에 대한
올바른 처방은 "피험자 불변 특징"이 아니라 "약한 신호에서도 잘 작동하는 표현
학습"이어야 한다는 결론이 더 명확해졌다. subject embedding을 유지하면서
adversarial 요소를 추가하는 방식(hard/easy 이진 도메인 적응 등)이 더 나은
접근이었을 수 있다.

50클래스 메인 순위 기준으로 v18(59.10%/37.89%)은 v1 이후 최저 성능이며,
추천 모델로 채택하지 않는다. 현재까지 50클래스 기준 최고는 v9/v10
(피험자별 fine-tuning, 69.07~69.10%)이다.


[향후 개선 후보 (v18 시점까지 미착수)]

- subject embedding 유지 + 이진 도메인 적응: hard/easy 두 그룹만 구분하는
  도메인 분류기를 추가하되 subject embedding은 그대로 사용. DANN의 "피험자
  정보 제거" 부작용 없이 hard-easy 경계를 직접 타겟할 수 있는 변형.
- 에포크 수 늘리기: val_f1이 30 에포크 내내 상승세였으므로 50~60 에포크로
  늘리면 더 수렴할 가능성 있음 — 단 근본 원인(subject embedding 제거 손실)은
  해결되지 않으므로 기대 상한이 낮음.
- 40명 개별 모델 학습 후 평균 정확도로 baseline(82.7%)과 진짜 동일 조건 비교
  (v9부터 계속 미뤄지는 항목).
- 데이터 증강: 어려운 피험자의 신호를 합성/증강해서 학습 데이터 불균형 완화.
