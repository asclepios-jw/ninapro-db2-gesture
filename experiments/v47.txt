[1] 이 모델/설정을 선택한 계기 — 결정의 맥락

v46 앙상블(특징 모델 4개)이 72.32%·미포화. 4개가 모두 특징 모델(v8 계열)이라
비슷했다. 이미 학습된 '다른 backbone/훈련' 체크포인트를 더해 다양성을 키우면
더 오를 것으로 판단. 재학습 0(추론만).


[2] 전 버전(v46)과 달라진 점

후보 7개로 확장 (모두 전처리전달_v28, 같은 test 입력, 재학습 없음):
  v44_orig/rep1/rep2  v8+TD       (70.2%)   특징 (v46 멤버)
  v45                 v8+TD+FD    (70.3%)   특징 (v46 멤버)
  v40                 v8 plain    (70.05%)  특징 없는 헤드 ← 추가
  v41                 Residual CNN(69.97%)  다른 backbone ★ ← 추가
  v38                 v8 long100  (69.48%)  다른 훈련 ← 추가

방법: 각 후보 test 확률 1회 계산 → 모든 부분집합(127개) acc 전수 평가 →
      최고 조합 탐색.


[3] 변경 이유 + 기대했던 효과

앙상블 이득은 멤버 간 오류 비상관에서 온다. 같은 arch·특징 모델끼리는 오류가
상관될 수 있으므로, 다른 backbone(v41)·다른 헤드(v40)·다른 훈련(v38)을 더하면
비상관 다양성이 커져 더 큰 이득 기대.

기대: 72.32% → 73% 근접/돌파.


[4] 기대와 실제가 어떻게 달랐는가

기대: 73% 근접/돌파
실제: **72.91%** — 73%에 0.09p 차. 다양성 효과는 확인, 그러나 미달.

  크기별 최고 조합 acc:
    1: 70.31% (v45)
    2: 71.73% (v44_rep2+v38)
    3: 72.37% (v44_orig+v41+v38)
    4: 72.61% (v44_orig+v45+v41+v38)   ← v46의 특징4개(72.32%)를 상회
    5: 72.78%
    6: 72.89%
    7: 72.91% (전체)

  최고(7개): 72.91%  hard 63.12%  easy 74.30%  macroF1 0.6433
  v46(72.32%) 대비 +0.59p.

**핵심:**
  1. 아키텍처 다양성이 실제로 기여. 최고 조합에 v41(Residual, 다른 backbone)
     포함 확인. 크기 3~4의 최고 조합도 v41·v38(비특징 다양성)을 포함.
  2. hard 63.12%(v46 62.17% 대비 +0.95p), macroF1 0.6433(0.6334 대비 +0.01)
     — hard·macro-F1도 동반 상승, 역대 최고.
  3. 그러나 6→7 증분 +0.02p로 기존 체크포인트 풀 안에서는 사실상 포화.
     73%(0.09p 더)를 넘으려면 새로운 비상관 다양성(신선한 멤버)이 필요.


[5] 학습 중 예상치 못하게 발생한 문제들

문제 없음(추론만). v41은 models_v41(Residual)로, v40/v38은 models_v8로,
특징 모델은 각 클래스로 로드 — 모두 같은 test 확률 공간(50클래스, 동일
LabelEncoder)에서 평균. 누수 없음(전부 test rep6 미노출 학습).


[6] 이번 버전에서 배운 점

**앙상블은 '정확도'보다 '다양성'을 먹는다.**
  추가한 v40/v41/v38은 개별론 더 약한 모델(69.5~70.05%)인데도, 강한
  특징 모델 4개(70.2~70.3%)만의 앙상블(72.32%)을 72.91%로 끌어올렸다.
  약해도 비상관이면 앙상블에 기여 — 특히 다른 backbone(v41)이 값졌다.

**막다른 길로 분류했던 실험들이 앙상블 재료로 부활.**
  v41(backbone 확대, 단독 무효)·v38(장기학습, 단독 미미)이 앙상블에서는
  다양성 공급원으로 유용. "단독 실패 ≠ 무가치".

**기존 자산 풀은 72.91%에서 포화.**
  7개로 6→7 +0.02p. 73%를 넘으려면 기존 체크포인트가 아닌 신선한 멤버가
  필요.


[7] 다음 — 73% 돌파 시도 (진행 중)

72.91%는 73%에 0.09p 차. 기존 풀은 포화 → 신선한 강한 멤버를 추가 학습.
  계획: v45(TD+FD arch, 현재 앙상블에 1개뿐)을 새 seed 2개로 pooled 학습
       (v45_rep1 seed111, v45_rep2 seed222). 강한 모델(70.3%급) + 새 seed
       다양성 → 9개 후보로 확장 sweep.
  기대: 강한 신선 멤버 2개 추가로 +0.1~0.2p → 73% 돌파.
  비용: pooled만 필요(앙상블은 base만 씀) → 2×~110분 ≈ 3.7시간.

  ※ 배포 관점: 7~9개 앙상블은 추론 ×N. 효율 필요시 4개(72.6%)로 대부분
     이득 유지 가능(v47 sweep). 균일(라벨/개인데이터 0)은 유지.
