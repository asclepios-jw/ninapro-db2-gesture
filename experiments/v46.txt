v46 — 특징 모델 4개 확률 평균 앙상블: 72.32%
       ★ 큰 도약(+2.01p) ★ — 단일 모델 정체가 진짜 천장이 아니었다
================================================================


[1] 이 모델/설정을 선택한 계기 — 결정의 맥락

v44(TD)·v45(TD+FD) 특징 추가의 증분이 diminishing(각 ~+0.1p, hard ~60.3
정체). 특징을 더 쌓기보다, 이미 학습해둔 다양한 강한 모델을 앙상블해
headroom을 확인·뱅킹하는 게 낫다고 판단(v45 [7]에서 1순위).

거의 공짜: 재학습 없이 추론만. 마침 v44를 3회(원본+rep1+rep2) 재현하며 얻은
체크포인트 + v45 = 4개 모델이 이미 있음.


[2] 전 버전들과의 관계 (앙상블이라 '변경'이 아니라 '결합')

앙상블 멤버 (모두 pooled base, test rep6에서 평가):
  v44 원본   TD arch,    seed 무    70.20%
  v44 rep1   TD arch,    seed 101   70.15%
  v44 rep2   TD arch,    seed 202   70.31%
  v45        TD+FD arch, seed 무    70.31%

방법: 각 모델의 test softmax 확률을 구해 평균 → argmax (확률 평균 앙상블).
     재학습·미세조정 없음. 추론만.


[3] 변경 이유 + 기대했던 효과

서로 다른 seed(증강 궤적)·아키텍처(TD vs TD+FD)의 모델은 경계 윈도우에서
서로 다른 실수를 한다. 확률을 평균하면 decorrelated error가 상쇄되어
더 안정적인 예측이 된다.

기대: +0.3~0.5p (전형적 앙상블 이득).


[4] 기대와 실제가 어떻게 달랐는가

기대: +0.3~0.5p
실제: **+2.01p** — 기대의 4~6배. 큰 도약.

  멤버(pooled)          acc      macroF1   hard     easy
  ───────────────────  ──────   ───────   ──────   ──────
  v44 원본             70.20%   0.5991    60.11%   71.64%
  v44 rep1             70.15%   0.5984    59.45%   71.68%
  v44 rep2             70.31%   0.5998    60.12%   71.76%
  v45                  70.31%   0.6002    59.98%   71.78%
  ───────────────────  ──────   ───────   ──────   ──────
  앙상블 v44×3         72.04%   0.6285    61.87%   73.49%
  앙상블 all4          72.32%   0.6334    62.17%   73.77%

  vs 최고 단일 pooled(70.31%): v44×3 +1.73p / all4 +2.01p
  소요: 0.8분 (추론만)

**핵심:**
  1. all4 앙상블 72.32%는 pooled 레벨인데도, 최고 '적응형' 단일 챔피언
     v45(70.59%)를 +1.73p 앞선다. 개인 데이터·라벨 없이(균일) 달성.
  2. hard 62.17% — v44/v45에서 ~60.3에 정체했던 hard를 처음으로 +2p 돌파.
  3. macro-F1 0.6334 — 0.60 언저리에서 크게 상승. 희귀 클래스도 개선.
  4. v44×3(동일 arch, seed만 다름)만으로 +1.73p → 이득의 대부분은
     seed 다양성(증강 궤적 차이)에서. v45(arch 다양성) 추가로 +0.28p 더.


[5] 학습 중 예상치 못하게 발생한 문제들

문제 없음(추론만). 누수 없음 확인:
  · 모든 멤버는 train(rep1-4)/val(rep5)로 학습, test(rep6)는 미노출.
  · 앙상블은 그 test에서 각 확률을 평균했을 뿐 → 정당한 held-out 평가.
  · LabelEncoder를 동일 y_train으로 fit해 클래스 순서 일치 확인.

+2p가 커 보이지만 근거 있음: 50클래스·단일 70% 수준에서 모델들이 경계
윈도우에 서로 다른 오류를 내면 확률 평균의 이득이 크게 나온다. 동일 arch
seed 다양성만으로 +1.73p는 상단이나 정상 범위.


[6] 이번 버전에서 배운 점

**단일 모델 정체(~70.5%)는 진짜 천장이 아니었다.**
  v40~v45에서 단일 모델은 +0.1p 단위로 기어갔지만, 앙상블은 +2p를 뱅킹.
  개별 모델의 예측 분산(경계 윈도우의 불확실성)이 컸고, 평균이 이를 흡수.
  → 정체기에는 '더 나은 단일 모델'보다 '여러 모델의 결합'이 큰 레버.

**앙상블이 hard 정체와 macro-F1까지 뚫었다.**
  hard 60.3→62.2, macro-F1 0.60→0.633. 특징 추가로도 안 되던 두 벽을
  다양성 결합이 넘었다. 서로 다른 모델이 서로 다른 어려운 케이스를 커버.

**공짜 자산의 가치.**
  재현 검증(v44 ×3)으로 얻은 체크포인트가 앙상블 재료가 됐다. 재현은
  검증이자 자산 축적이었다.

**배포 관점 trade-off (명시).**
  앙상블은 개인 데이터·hard/easy 라벨 불필요(균일) → 미팅 피드백과 일관.
  단 추론 비용 ×4. 단, 윈도우당 forward가 sub-ms라 4×도 실사용 지장 낮음.


[7] 다음 버전에서 고쳐볼 점 + 기대 효과

앙상블이 큰 headroom을 열었으므로 이 축을 정리·심화:

1. **(재현/확정) 앙상블 결과 안정성**
   현재 멤버 4개로 72.32%. 멤버 수·구성 바꿔가며 안정성 확인.
   더 다양한 모델(다른 arch/seed) 추가 시 추가 이득 가능.

2. **(잠재적 최고) 앙상블 + adaptive fine-tuning**
   현재 앙상블은 pooled. 단일에서 adaptive가 +0.25~0.30p였음.
   앙상블 예측을 피험자별로 보정하는 방법(앙상블 로짓에 per-subject 헤드
   미세조정 등) 설계 시 72.5~72.6% 잠재. 단 구현 복잡.

3. **(효율) TTA 또는 멤버 수 최소화**
   4× 추론이 부담이면, 2~3개로 대부분 이득 유지되는지(v44×3=+1.73p 이미
   확인) 또는 TTA로 대체 검토.

4. **(정직성) 앙상블 vs 단일 프레이밍**
   보고 시 "단일 배포 모델 70.6% / 앙상블 72.3%(추론 4×)"를 함께 제시.

[멤버 sweep — 견고성·효율 확인 (추론만, 15개 부분집합 전수 평가)]

4개 멤버의 test 확률을 1회 계산 후 모든 비어있지 않은 조합(15개)을 평가.

  크기  조합수   acc min~max        최고 단일 대비    비고
  ────  ──────  ─────────────────  ────────────────  ──────────────
  1     4       70.15 ~ 70.31%     (기준)             단일 모델
  2     6       71.55 ~ 71.67%     +1.24 ~ +1.36p     쌍
  3     4       72.04 ~ 72.14%     +1.73 ~ +1.83p     삼중
  4     1       72.32%             +2.01p             전체

발견:
  1. 견고성 확정 — 특정 4개의 우연이 아니다.
     같은 크기의 '모든' 조합이 거의 동일한 이득(2개 범위 0.12p, 3개 범위
     0.10p). 즉 어떤 2개든 +1.3p, 어떤 3개든 +1.8p. 앙상블 이득은 멤버
     구성에 무관한 일반적 현상.
  2. 효율 프론티어 (배포 추론비용 trade-off).
     2개 → +1.3p(71.6%), 3개 → +1.8p(72.1%), 4개 → +2.0p(72.3%).
     추론 ×N이 부담이면 2~3개로 대부분 이득 확보 가능.
  3. 4개에서 아직 포화 아님 (3→4 증분 +0.18p).
     → 더 다양한 멤버(다른 arch/seed) 추가 시 72.5~73%까지 더 오를 여지.

결론: +2.01p 앙상블은 견고하고(조합 무관) 곡선이 매끄러우며 미포화.
     이 결과를 신뢰하고 보고 가능. 추가 멤버로 더 밀거나, 2~3개로 효율화
     하거나, 여기서 확정 후 adaptive 결합을 시도할 수 있음.
