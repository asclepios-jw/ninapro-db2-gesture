================================================================
v45 — TD + 주파수영역 특징(FD): 70.59%
       신기록 — TD는 hard를, FD는 easy/전체를 올린다 (상보적 위치)
================================================================


[1] 이 모델/설정을 선택한 계기 — 결정의 맥락

v44(TD 특징)가 hard를 균일하게 개선(+0.93p, 3회 재현 검증). '정보 추가'
방향이 검증됐으므로 심화. 주파수영역 특징(FD)은 근피로·발화율(스펙트럼 분포)을
담아 시간영역(진폭/복잡도)과 상보적일 것으로 기대.

가설: FD 추가 → 특히 hard 추가 개선 + 전체 소폭 상승.


[2] 전 버전(v44)과 달라진 점

유일한 변경: 특징 세트에 FD 추가.
  models_v44 (TD 60)
  → models_v45.SubjectAwareCNNLSTMAttentionFeatFD (TD 60 + FD 36 = 96)

  FD 특징 (12 EMG 채널, FFT 기반):
    MNF(mean freq) : Σ(f·P)/ΣP — 스펙트럼 무게중심
    MDF(median freq): 누적 파워 절반 지점 — 피로 지표
    PKF(peak freq) : 최대 파워 주파수
    = 3 × 12 = 36. 정규화 불변(비율/argmax).
  파라미터: 819,154 (v44 816,778 대비 +2.4K) — 여전히 '정보'이지 '용량' 아님.

증강·손실·아키텍처 골격은 v44와 동일.


[3] 변경 이유 + 기대했던 효과

TD(RMS/MAV/WL/ZC/SSC)는 진폭·복잡도를, FD(MNF/MDF/PKF)는 주파수 분포를 담는다.
근전도에서 이 둘은 전통적으로 상보적. 특히 저 SNR 신호에서 스펙트럼 지표가
안정적이라 hard에 추가로 도움될 것으로 기대.

기대: hard 추가 개선 + 전체 +0.1~0.3p.


[4] 기대와 실제가 어떻게 달랐는가

기대: hard 추가 개선 중심
실제: **신기록(+0.14p), 그러나 이득은 easy/전체에서 왔다.**

  [pooled base]
    v45b: 70.31%  (v44b 70.20% 대비 +0.11p)
    hard 59.98%(v44b 60.11% 대비 −0.13p), easy 71.78%, gap 11.80p
    macro-F1 0.6002 ← 처음으로 0.60 돌파 (v44b 0.5991)
    best epoch 44 (수렴)
  [최종 adaptive]
    v45: 70.59%  (v44 70.45% 대비 +0.14p / v40 70.35% 대비 +0.24p) ← 신기록
    hard 60.36%(v44 60.29% 대비 +0.07p ≈ 동일)
    easy 72.05%(v44 71.90% 대비 +0.15p)  ← 이득의 원천
    선택: FT 38명 / BASE 2명

**핵심 발견: TD와 FD는 '어디를 돕는지'가 다르다.**
  v44(TD 추가): hard +0.93p (easy 거의 불변)
  v45(FD 추가): easy +0.15p (hard 거의 불변, ~60.3 정체)
  → TD는 저 SNR(hard)에서 학습 특징을 보완, FD는 잘 되는 신호(easy)에서
    스펙트럼 정보로 추가 변별. 둘은 서로 다른 구간을 채우는 상보재.

  macro-F1이 처음 0.60을 넘음 → 희귀 클래스 변별도 소폭 개선.


[5] 학습 중 예상치 못하게 발생한 문제들

코드 문제: 없음. 스모크 테스트로 FD 계산 정확성(범위 0~1000Hz, Nyquist 내),
  forward/backward, freeze_cnn 호환 사전 검증.
  (스모크의 MNF~500Hz는 백색소음 기준 정상값; 실제 EMG에선 대역 반영해 낮음.)

관찰: val 추이가 학습 내내 v44와 거의 겹침 → FD의 증분이 작다는 신호였고
     실제로도 +0.14p로 겸손. 계산·수렴 이상 없음.


[6] 이번 버전에서 배운 점

**특징 패밀리마다 돕는 구간이 다르다 — 다양성이 곧 커버리지다.**
  TD → hard(저 SNR), FD → easy/전체. 한 종류로는 특정 구간만 채운다.
  여러 특징 패밀리를 함께 넣으면 서로 다른 실패 모드를 나눠 커버.

**'정보 추가' 방향은 계속 유효하나 증분이 줄고 있다.**
  TD +0.10p → FD +0.14p, 둘 다 작고, hard는 ~60.3에서 정체.
  → 특징을 더 쌓는 것의 한계 효용이 보이기 시작. 다음 큰 이득은 다른 축.

**macro-F1 0.60 돌파.**
  누적된 특징 추가가 희귀 클래스에도 조금씩 도움. 다만 acc(70.6)와의 격차는
  여전히 커(불균형 근본 문제는 남음).

**주의: +0.14p는 단일 run.**
  v44는 3회 재현(70.49±0.04)으로 확정했으나 v45는 1회. 70.59는 v44 분포보다
  뚜렷이 위(약 +0.10p, 2.5σ)라 실질일 가능성이 높으나, 확정하려면 재현 필요.


[7] 다음 버전에서 고쳐볼 점 + 기대 효과 (→ v46 방향 결정)

특징 추가의 증분이 diminishing(TD+0.10, FD+0.14, hard 정체)이므로, 특징을
더 쌓기보다 축적된 자산을 활용해 더 큰 이득을 뱅킹하는 게 낫다.

  1순위: 앙상블 (v46로 진행)
     지금 서로 다른 강한 pooled 모델이 이미 학습돼 있다:
       v44 원본/rep1/rep2 (TD arch, seed 무/101/202) + v45 (TD+FD arch)
     = 4개 다양한 모델. test 확률 평균(로짓/softmax 앙상블)은 거의 공짜
     (추론만, 재학습 없음)이고 신뢰도 높은 이득(+0.3~0.5p 기대).
     '특징 추가 정체' 국면에서 headroom을 확인하는 자연스러운 다음 수.
     ※ 배포 시 추론 비용 ×N은 trade-off로 명시.

  2순위: AR 계수 등 특징 추가 — 같은 방향이나 증분 더 작을 것.
  3순위: 융합 방식 개선(gated/early fusion) — 불확실.

  → v46 = 앙상블 (이미 학습된 v44×3 + v45 pooled 모델 확률 평균).
