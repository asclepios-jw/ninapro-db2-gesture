================================================================
v21 — 40명 개별 모델 baseline: pooled 모델의 손해가 없음을 확인
================================================================

[이 버전을 시작한 계기]

v18~v20에서 DANN 계열 세 버전을 시도했으나 전체 정확도가 v8(68.69%)을 단 한 번도
넘지 못했다. DANN gap 역전 원인 분석 결과, hard/easy 격차가 "cross-subject 혼재"
때문인지 "피험자 본연의 특성" 때문인지를 알지 못한 채 방법론만 바꾸고 있었음이 드러났다.

이를 검증하기 위해 가장 단순한 실험: 40명 각각에 대해 독립 모델을 학습하여
(1) 개별 모델 평균 성능 vs pooled 모델 비교 → pooling 비용이 실제로 있는가?
(2) 개별 모델에서도 hard/easy gap이 유지되는가? → gap이 데이터 본연의 특성인가?


[방법: code/train_cnn_v21.py]

아키텍처: v8/v9와 동일한 CNN+BiLSTM+attention. subject embedding 없음(단일 피험자
모델에서는 불필요). Linear head: 256 → n_classes (피험자마다 LabelEncoder 독립 적용).

정규화: 피험자 본인의 train 윈도우에서 mean/std 계산 후 val/test에 적용.
(norm_mean.npy는 전체 평균이므로 사용하지 않음)

피험자 루프: s=1..40 순서로 순차 학습. 각 피험자 종료 후 torch.cuda.empty_cache().
하이퍼파라미터: N_EPOCHS=30, PATIENCE=6, BATCH_SIZE=256, LR=1e-3,
               WEIGHT_DECAY=1e-4, CosineAnnealingLR, label_smoothing=0.1

체크포인트: val macro-F1 기준 best 저장(_tmp_ckpt.pth) → 테스트 후 삭제.
           (모델 40개 저장 불필요 — baseline 수치만 필요)

[기대와 실제가 어떻게 달랐는가]

기대: 개별 모델은 다른 피험자의 노이즈를 받지 않으므로 pooled 대비 눈에 띄게 높아야
한다 (예: 75~80% 이상). 특히 hard 피험자는 pooled 모델에서 다른 피험자 정보에 묻혀
손해를 보고 있을 것이므로 개별 모델에서 크게 개선될 것이라 예상했다.

실제: 전체 평균 69.00% vs pooled 68.69% — 차이 0.31%. Hard 피험자는
57.52% → 57.59% — 차이 0.07%. 사실상 동일하다.

예측과 결과의 격차가 매우 크다. 40명 분리 학습이라는 가장 "확실한" 개인화 방법이
pooled 대비 아무 이득을 주지 못한다는 것은 처음에는 직관에 반하지만, 설명은 명확하다.


[원인 분석: gap이 데이터 본연의 특성임을 확인]

v21 결과는 두 가지를 동시에 확인해준다:

1. Pooling 비용이 없다.
   개별 모델 ≈ pooled 모델이라는 것은, 40명을 합쳐도 각 피험자의 성능을 희생시키지
   않는다는 의미다. 오히려 pooled 모델은 더 많은 학습 데이터(×40)를 활용하면서
   동등한 성능을 낸다. v8이 이미 최적에 가까운 모델이었음을 사후에 확인한 것.

2. Hard/easy gap은 데이터 본연의 특성이다.
   개별 모델에서도 hard 5명 평균이 57.59%에 머문다. cross-subject 혼재를 완전히
   제거했음에도 gap(13.04p)은 오히려 pooled(12.77p)보다 약간 더 크다. 즉 hard 피험자의
   낮은 성능은 "pooled 모델이 easy 피험자를 더 잘 학습하기 때문"이 아니라,
   그 피험자의 sEMG 신호 자체가 50클래스를 구분하기 어렵게 분포되어 있기 때문이다.
   (더 높은 피험자 간 변동성, 피로, 전극 위치 편차, 생리적 특성 등이 원인일 수 있음)

3. Easy 분류 내에도 스펙트럼이 존재한다.
   Sub 17(60.44%), 18(61.29%), 38(61.45%)는 hard로 분류되지 않았지만 실제 성능이
   hard 피험자(57~62%)와 겹친다. 이는 hard/easy 이진 분류보다 연속적인 "피험자별
   난이도 스펙트럼"이 더 정확한 표현임을 시사한다.

이 분석은 v18~v20 DANN 실험의 근본적 문제를 드러낸다: DANN은 "pooling으로 인해
hard 피험자가 손해를 본다"는 가설 위에서 설계됐는데, v21은 그 가설이 틀렸음을 증명한다.
cross-subject 적응보다는 hard 피험자의 신호 자체를 잘 다루는 방향이 맞다.


[v1~v21 전체를 관통하는 결론]

  현재까지 최고 성능 요약 (test acc 기준):
    v10  69.10%  (pooled + subject emb + 50epoch)
    v9   69.07%  (pooled + subject emb + 30epoch)
    v21  69.00%  (개별 40모델 평균)
    v8   68.69%  (pooled + subject emb + 30epoch)

  v21은 세 가지 질문에 답했다:
  (1) 개별 모델이 pooled보다 유의미하게 높은가? → NO (0.31p 차이)
  (2) Hard 피험자가 pooled 때문에 손해를 보는가? → NO (0.07p 차이)
  (3) Gap이 데이터 본연의 특성인가? → YES (개별 모델에서 13.04p gap 유지)

  이로써 "피험자 간 도메인 차이 완화"라는 방향(v18~v20)의 근거가 사라졌다.
  다음 단계는 hard 피험자의 신호 자체를 더 잘 처리하는 방법, 또는 전체 정확도를
  69% 이상으로 끌어올리는 아키텍처 개선에 집중해야 한다.


[향후 개선 후보 (v21 시점까지 미착수)]

- (신규) 피험자별 성능 분포 시각화: easy 35명 내에서도 60~85%까지 분산이 크다.
  피험자별 난이도 스펙트럼을 이해하면 어떤 피험자를 개선할 여지가 있는지 파악 가능.

- (신규) Hard 피험자 전용 데이터 증강: hard 피험자의 개별 모델도 57~62%에 머물렀다.
  신호 수준에서 노이즈 추가, 스케일 변화, 채널 드롭아웃 등 증강으로 일반화를 높이는 시도.

- (신규) 에포크 증가 실험: 상당수 피험자(419s로 조기종료 없이 30epoch 완료)가 val_f1을
  30에포크 끝까지 올리고 있을 가능성. 50epoch 시도 가치 있음.

- (이전부터) 더 깊거나 넓은 아키텍처: CNN 채널 수 증가(128→256), LSTM hidden 증가,
  Transformer self-attention 교체 등. 현재 아키텍처는 v8부터 고정돼 있음.

- (이전부터) 피험자 간 앙상블: 피험자 유사도 기반 소규모 클러스터 모델 → 개별보다
  데이터 많고 pooled보다 간섭 적은 중간 전략. v21이 pooling 손해 없음을 보였으므로
  앙상블 이득은 제한적일 수 있음.
