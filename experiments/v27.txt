[기대와 실제가 어떻게 달랐는가]

기대: 10Hz 필터 수정으로 v10 수준(69%) 근접 회복.
     temporal variation 분석 (0.0748 vs 0.1312)이 필터를 주원인으로 지목했으므로
     최소 5~6p 회복 기대.

실제: +0.98p. 필터 변경은 부수적 원인에 불과.

결론: **엔벨로프 컷오프 5Hz→10Hz는 성능 갭의 주원인이 아니다.**
      envelope std 비율(0.161 → 0.278)은 바뀌었지만 모델 성능엔 미미한 영향.

우리 v8과 팀 코드 간 남은 구조적 차이:

  1. 정규화 순서 (유력 후보)
     우리 v8: 연속 EMG 정규화 → |EMG| → lowpass → envelope
              → envelope이 "정규화된 신호"의 절댓값
     팀 코드: |EMG| → lowpass → envelope, 이후 [EMG, envelope] 전체 정규화
              → envelope이 "원시 신호"의 envelope을 정규화한 것
              → 두 방식에서 envelope 채널의 의미가 다름

  2. 정규화 통계 계산 기준
     우리 v8: 연속 시계열 전체 (train rep)에서 mean/std 계산
     팀 코드: 윈도우 데이터 (stride 150ms, 오버랩 50%) 에서 계산
              → 오버랩으로 제스처 구간 가중 → 통계 편향 가능성

  3. rep=0 윈도우
     우리 v8: 포함 (563 train 윈도우 추가, rest 클래스 증가)
     팀 코드: 명시적 제외 (전이 구간 폐기)
