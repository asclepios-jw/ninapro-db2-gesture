================================================================
v40 — 강한 증강 pooled + adaptive fine-tuning: 70.35%
       ★ 70% 돌파 ★ — 가설 검증: 증강은 fine-tuning과 상보적
================================================================


[1] 이 모델/설정을 선택한 계기 — 결정의 맥락

v39에서 "장기 학습은 fine-tuning과 대체 관계(궁합 나쁨)"임이 확인됐다.
base를 올리되 fine-tuning 이득을 해치지 않는 레버가 필요했다.

핵심 통찰(v37+v39 종합):
  - backbone(CNN)을 개선하는 레버 → 상위 레이어 개인화 여지 보존 → 시너지
  - 상위 레이어를 개선하는 레버(장기학습) → 개인화 여지 소진 → 대체

증강은 backbone(공통 특징 추출기)을 개선하는 레버다.
→ 따라서 증강을 강화하면 base가 오르면서도 fine-tuning 이득이 보존될 것.

가설: 증강 강도 상향 → pooled base ↑ → 그 위 adaptive fine-tuning까지 → 70% 돌파.


[2] 전 버전과 달라진 점

v40은 2단계 파이프라인:
  (1) train_cnn_v40.py : 강한 증강으로 pooled 학습 → best_model_v40.pth
  (2) finetune_v40.py  : 그 base에 v37식 adaptive fine-tuning → 최종

v36(증강 표준 강도, 50ep) 대비 증강 강도 3개만 상향:
  MAGWARP_SIGMA  0.20 → 0.30
  TIMEWARP_SIGMA 0.15 → 0.25
  MIXUP_ALPHA    0.20 → 0.30
  (jitter σ=0.06, 확률 0.5, 50ep, T_max=50, patience=8, focal γ=2 는 v36 그대로)

의도적으로 50ep 유지 (장기학습 100ep 채택 안 함 — v39 교훈).
fine-tuning은 v37/v39와 100% 동일 (freeze_cnn, Adam 1e-4, 15ep, adaptive 선택).


[3] 변경 이유 + 기대했던 효과

증강 강화의 이론:
  근전도는 전극 위치·근피로·착용 편차로 변동이 크다. 더 강한 magnitude/
  time warp은 그 변동을 더 넓게 모사하고, 더 강한 mixup은 결정 경계를 더
  부드럽게 만든다. v36의 보수적 설정에서 아직 일반화 여지가 남아 있었다
  (v36에서도 tr<val, 과적합 없음 → 증강을 더 줄 여유 있었다).

기대: base +0.1~0.3p → 최종 70.0~70.1% (조심스럽게 70% 돌파).


[4] 기대와 실제가 어떻게 달랐는가

기대: base +0.1~0.3p → 최종 70.0~70.1%
실제: **base +0.80p (70.05%!) → 최종 70.35%** — 기대를 크게 초과.

  [1단계 pooled base]
    overall : 70.05%  (v36 69.25% 대비 +0.80p)  ← pooled 단일 모델 최초 70% 돌파
    macro-F1: 0.5974  (v36 0.5874 대비 +0.0100)
    hard    : 59.54%   easy : 71.54%   gap : 12.00p
    best epoch = 50 (마지막까지 상승, 미수렴 — 그러나 50ep 유지)

  [2단계 최종 (adaptive fine-tuning)]
    overall : 70.35%  (base 70.04% 대비 +0.31p)  ← 전체 최고
    hard    : 59.36%   easy : 71.92%
    선택 통계: FT 36명 / BASE 4명

**두 가지가 기대를 넘었다:**

(1) 증강 강화가 base를 +0.80p나 올렸다 (기대 +0.1~0.3p의 3~8배).
    강한 증강 50ep(70.05%)이 장기학습 100ep(v38, 69.48%)를 +0.57p 앞섰고,
    학습 시간은 절반. → base를 올리는 데는 "장기학습"보다 "강한 증강"이
    훨씬 효율적인 레버.

(2) fine-tuning 이득이 보존됐다 (+0.31p, FT 36명).
    v39(장기학습 base)에서는 FT 26명 / +0.18p로 쪼그라들었는데,
    v40에서는 FT 36명(역대 최다) / +0.31p. → 증강 base는 개인화 여지를
    소진하지 않는다는 가설이 정확히 검증됐다.

  파이프라인 궁합 비교 (fine-tuning 이득, base 종류별):
    v37: v36(표준증강) base    → +0.58p, FT 33명   (상보)
    v40: v40(강한증강) base    → +0.31p, FT 36명   (상보, 이득은 다소 축소)
    v39: v38(장기학습) base    → +0.18p, FT 26명   (대체)
    → 증강 계열은 모두 FT 30명 이상 채택 = 개인화 여지 보존. 장기학습만 예외.


[5] 학습 중 예상치 못하게 발생한 문제들

기술적 문제: 없음. (도커 ninapro-dev, /usr/local/bin/python, torch 2.12+cu130.
  pooled → finetune를 && 로 연결해 하나의 백그라운드 작업으로 순차 실행.)

hard subject fine-tuning의 불안정성 재확인:
  5명 모두 val 기준 FT로 선택됐으나, test에서는 3명이 오히려 악화:
    s04: base 0.5886 → ft 0.5721 (-1.65p, val 오판)
    s07: base 0.6414 → ft 0.6377 (-0.37p, val 오판)
    s31: base 0.5597 → ft 0.5462 (-1.35p, val 오판)
    s26: base 0.6275 → ft 0.6448 (+1.73p, 정상)
    s28: base 0.5608 → ft 0.5671 (+0.63p, 정상)
  → 그 결과 hard acc가 pooled 59.54% → 최종 59.36%로 소폭 하락.
    hard subject는 val 데이터가 적고 노이즈가 커 val≠test가 잦다.
    (전체 평균은 easy 개선으로 상승했지만, hard는 fine-tuning이 역효과.)

best_epoch=50 관찰:
  pooled가 50ep 끝까지 상승 중(미수렴). 장기학습 유혹이 있으나 v39 교훈에
  따라 50ep 유지. 100ep로 늘리면 base는 더 오를 수 있으나 fine-tuning
  궁합이 나빠질 위험 → 현 시점에선 50ep가 파이프라인 전체 최적.


[6] 이번 버전에서 배운 점

**증강 강화는 base를 올리는 가장 효율적인 레버이며, fine-tuning과 상보적이다.**

  base를 올리는 두 레버 비교:
    장기학습 100ep (v38): +0.23p, 3.8시간, fine-tuning과 대체(궁합 나쁨)
    강한 증강 50ep (v40): +0.80p, 1.8시간, fine-tuning과 상보(궁합 좋음)
  → 증강 강화가 시간은 절반, 이득은 3배, 게다가 fine-tuning까지 살린다.

  이는 v37+v39에서 세운 원칙("개선 위치가 궁합을 가른다")의 실전 검증이다.
  backbone을 건드리는 레버(증강)를 강화하는 게 정답이었다.

**과적합이 없는 모델에는 증강을 더 줄 여지가 있다.**
  v36도 tr<val(과적합 없음)이었는데, 그건 "증강이 딱 맞다"가 아니라
  "더 줘도 된다"는 신호였다. 강도를 올리자 base가 +0.80p 뛰었다.
  → 과적합이 사라졌다고 증강을 멈출 게 아니라, 성능이 오르는 한 더 준다.

**그러나 hard subject는 여전히 fine-tuning의 사각지대다.**
  강한 증강으로 hard base는 올랐지만(pooled hard 59.54%), fine-tuning은
  hard에서 여전히 불안정(3/5 악화). hard는 개인화보다 일반화(증강)로
  올리는 게 안전하다.

**★ 70% 돌파 — 프로젝트 이정표.**
  v10(69.10%, 오랜 목표)을 넘은 지(v37) 얼마 안 돼 70%까지 돌파.
  전체 여정: v25(팀데이터 62.58%) → v40(70.35%) = +7.77p.


[7] 다음 버전에서 고쳐볼 점 + 기대 효과

1. **(v41, 우선) 증강 강도 추가 탐색 — 최적점 찾기**
   v40에서 강도↑가 +0.80p를 줬다. 더 올리면? 아니면 이미 지났나?
   magwarp/timewarp/mixup를 한 단계 더(σ 0.40 / 0.35, α 0.40) 또는
   개별 grid로 최적점 탐색. 과하면 신호가 뭉개져 역효과 → val로 확인.
   기대: +0.1~0.3p (또는 v40이 최적임을 확인).

2. **(v42, 단기) hard subject는 fine-tuning 제외 (강제 BASE)**
   hard 5명은 fine-tuning이 반복적으로 불안정(v40에서 3/5 악화).
   adaptive 선택 대신 hard는 무조건 pooled base 사용하도록 규칙 추가.
   기대: hard acc pooled 수준(59.5%) 확보 → 전체 +0.05~0.1p + 안정성.

3. **(단기) 전극 shift 증강 추가**
   DB2 전완 둘레 전극 순환 shift로 착용 편차 모사. backbone 일반화 강화
   → 증강 계열이므로 fine-tuning과 상보 유지.
   기대: hard +0.3~0.5p, 최종 +0.1~0.2p.

4. **(중기, 2안) 아키텍처 업그레이드 + 강한 증강**
   증강이 backbone과 강하게 시너지냄을 확인(v36→v40 base +0.80p).
   더 강한 아키텍처(multi-scale/Transformer/residual)에 v40 증강+파이프라인.
   과거 v23/24 multi-scale 실패는 증강 없이 했기 때문 → 재도전 가치 높음.
   기대: +0.5~1.5p (분산 큼). 70%대 중반 가능성.

5. **(참고) 강한 증강 + 장기학습 조합은 신중히.**
   v40 base가 50ep 미수렴이라 100ep면 base는 더 오를 수 있으나,
   v39 교훈상 장기학습은 fine-tuning 궁합이 나쁨. base만 제출한다면 시도
   가치 있으나, 최종 파이프라인엔 권장 안 함.
