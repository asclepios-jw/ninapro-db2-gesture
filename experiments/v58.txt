================================================================
v58 — [안정화 2/3] 배포 구성 확정: 효율곡선 + 조합 robustness + 단일 fallback
       "최종 배포 모델"을 3단 스펙으로 고정
================================================================


[1] 계기
안정화 2단계. 앙상블은 추론 비용이 모델 수만큼 든다 → 비용 대비 성능을 정량화해
배포 구성을 하나로 고정한다. 재학습 0, 기존 8멤버 체크포인트 재사용.


[2] 방법 (추론만)
  · 8멤버 확률을 test에서 1회 계산.
  · 효율곡선: 모든 비어있지 않은 부분집합(255개)을 크기별로 묶어 프레임 acc의
    평균/최소/최대 → 크기별 성능 + 같은 크기 spread(조합 robustness).
  · 단일 fallback: 개별 멤버 최고 성능.


[3] 결과
  효율곡선(프레임 acc):
    N=1  70.09%  [69.48~70.31]      N=5  72.70%  [72.56~72.83]
    N=2  71.65%  [71.55~71.76]      N=6  72.82%  [72.70~72.91]
    N=3  72.22%  [72.04~72.37]      N=7  72.91%  [72.82~72.96]
    N=4  72.51%  [72.32~72.69]      N=8  73.00%  (단일 조합)
  단일 fallback(최고=v45): 프레임 70.31% / 동작단위 85.94% / hard 59.98%.


[4] 해석 (핵심)
  · 조합 robustness 우수: 같은 크기면 spread ±0.2p 이내 → 특정 멤버 선택에
    민감하지 않음(안정). v57 seed 분산과 일관.
  · 수확체감: N=4에서 72.51%(풀8 −0.49p), N=5에서 72.70%(−0.30p). 배포는 4~5면
    충분.
  · 다양성 우선: "단일 최고 5개"(전부 v44/v45 계열, 상관 높음)=72.56%로, 임의
    다양 5개(72.70%)보다 낮음 → 배포 구성은 아키텍처 다양성으로 골라야 함
    (v54 '다양성 강도 하한'과 일관).


[5] 확정 — 3단 배포 스펙
  1. 최소(1×)      단일 v45        프레임 70.3% / 동작단위 85.9%   엣지·최소
  2. 권장(4~5× 다양) v44+v45+v40+v41(+v38)  ~72.5% / ~87.5%       절반 비용
  3. 최대(8×)      champion(보고용)  73.0% / 88.0%                 최고 성능
