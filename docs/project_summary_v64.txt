근전도 제스처 분류: v1에서 v64까지 — 프로젝트 요약
Ninapro DB2 · sEMG 제스처 분류 · 날짜: 2026-07-12
현재 최고: 프레임 73.0%(±1.1) / 동작단위 88.0%(±0.8) — 균일 · 안정화·강건성 완료
================================================================

팔뚝 근전도(sEMG)만으로 50가지 손동작을 분류. 40명을 한 모델에 모아 범용성을
지향(개인 라벨·캘리브레이션 0). 64번의 실험으로 무엇이 통했고 무엇이 착시였는지(개발·안정화·강건성 완료).

  핵심 수치 (모두 개인데이터·라벨 0 = "균일"; 1회 등록 전제):
    프레임 정확도(실시간, 엄격)         : 73.0%  95%CI[70.8,75.3]±1.1p / macroF1 0.644
    동작 단위 정확도(Ninapro 표준)      : 88.0%  95%CI[86.4,89.6]±0.8p / macroF1 0.846 / hard 83.9%
    정직한 배포 동작단위(실제 분할)     : 80.4%  / hard 73.4%
    seed 분산 ±0.03p → 헤드라인 안정 확정(v57)
  전체 여정(프레임): 팀데이터 62.6%(v25) → 73.0%(v48) = +10.4p


================================================================
1. 문제
================================================================
  · 입력: 팔뚝 12전극 sEMG(2kHz) → 포락선 더해 24채널, 300ms 창.
  · 출력: 50가지 손동작.
  · 제약: 40명을 한 모델에 — 새 사용자도 통하는 범용 모델(개인화 0 지향).
  · 난점: 한 사람 맞춤은 82.7%이나 40명 묶으면 급락(사람마다 신호 다름).
          반복 주인공: 어려운 5명{S4,S7,S26,S28,S31}, easy–hard 격차.


================================================================
2. 무엇이 성능을 움직였나 (유효 레버, 크기순)
================================================================
  버그 수정(초기)        +7.5p   손실 보정 겹침 → "쉬운 동작 무시" 학습을 잡음
  올바른 아키텍처         +4.69p  팀데이터 급락의 범인은 전처리 아닌 아키텍처
  앙상블(후반 최대)       +2.7p   단일 정체(70.3%) → 여러 모델 결합 73.0%
  필터 5→10Hz            +0.98p
  라벨보존 증강           +0.80p
  시간·주파수 특징        +~0.3p  (hard 개선에 기여)

  → 소수의 큰 결정이 대부분. 정교한 튜닝(0.1p 단위)보다 방향이 중요했다.


================================================================
3. 돌파구 — 앙상블 (단일 정체가 진짜 천장이 아니었다)
================================================================
  · 단일 모델은 특징·증강 다 써도 70.3~70.6%에서 +0.1p 단위로 기어감.
  · 서로 다른 seed·아키텍처 8모델의 확률 평균 → 73.0% (재학습 0, 추론만).
  · 견고성: 같은 크기 '모든 조합'이 동일 이득 → 특정 멤버 우연 아님.
  · 한계: 멤버는 '비상관 + 충분히 강함' 둘 다 필요. 약한 다른-아키텍처
    (스펙트로그램 57%)는 선택은 되나 net 이득 0.
  · 배포: 전부 균일(개인데이터·라벨 0), 추론 비용만 N배.
    4~5모델로 72.7~72.8% 유지 가능(효율 곡선).


================================================================
4. ★ 결정적 재해석 — "73%"는 실제 성능이 아니었다 (평가 단위 착시)
================================================================
  프레임(윈도우)을 하나씩 채점하면 73%. 그러나 제스처 실행 단위(Ninapro 표준)
  로 다수결하면 경계의 순간 오류(제스처를 rest로 잠깐 놓침)가 사라진다.

  정직한 성능 계층 (모두 균일):
    처리                        acc      hard    전제
    ──────────────────────────  ──────   ──────  ─────────────────
    프레임(실시간)              73.0%    63.1%   지연0·엄격
    온라인 평활                 78.6%    72.4%   1.5~3s 지연
    실제 분할(정직)             80.4%    73.4%   예측으로 경계 검출
    학습 시간보정(hard 최선)    82.6%    79.8%   오프라인
    동작 단위(표준·문헌비교)    88.0%    83.9%   경계 앎(전제)

  · 낮은 macro-F1(0.64)도 '신호 한계'가 아니라 이 착시였다 →
    동작 단위 macro-F1은 0.85. (재균형으로 못 고쳤던 이유.)
  · 즉 실제 시스템 성능은 최소한의 시간 처리만으로 80%대, 표준 88%.


================================================================
5. 막다른 길 (값진 실패 — 재현 쉽고 원칙이 됨)
================================================================
  · 용량 확대(Residual CNN, 파라미터 1.8배): 이득 0 → "용량은 병목 아님".
  · 전극 shift 증강: −1.6p → 회전 불변성 가정이 DB2 근육 배치에 안 맞음
    (라벨-신호 불일치). "증강은 라벨 의미 보존해야".
  · macro-F1 재균형(후처리+학습): 둘 다 하락 → 편향 아닌 평가 단위 문제.
  · 장기학습·hard 라벨 처리·약한 다른-아키텍처 멤버: 무효/역효과.
  · 반전: 단독 실패한 모델(Residual/장기학습)도 앙상블 멤버로 부활 →
    "실패 ≠ 무가치".


================================================================
6. 외부 검토(MiniMax) 반영 — 방법론 엄밀성
================================================================
  · "macro-F1 신호 상한 결론 성급" → 평가 단위 재해석으로 이어져 88% 발견.
  · "pooled 앙상블 vs 개인적응 단일 비교 부당" → 같은 조건끼리 재프레이밍(+2.7p).
  · "+0.1p 이득 다수는 노이즈, hard/easy 코호트 순환성" → 과대주장 정정.
  → 자기검토로 놓친 '평가 단위 사각지대'를 외부 검토가 잡음.


================================================================
7. 교훈
================================================================
  L1. 소수의 큰 결정이 성능을 만든다(버그·아키텍처·앙상블). 튜닝은 0.1p 단위.
  L2. 용량이 아니라 정보·다양성. 단 앙상블 멤버엔 강도 하한 존재.
  L3. 평가 단위가 결론을 바꾼다(낮은 macro-F1은 프레임 단위 착시).
  L4. 증강은 라벨 의미를 보존해야(전극 shift 실패).
  L5. 진단과 처방이 맞아야(DANN·재균형 실패).
  L6. 외부 검토가 자기 사각지대를 잡는다.
