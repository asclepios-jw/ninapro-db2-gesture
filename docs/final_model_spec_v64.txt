1. 문제 정의 · 입출력 명세
================================================================================

[1.1] 과제
  팔뚝 표면 근전도(sEMG)만으로 사용자가 의도한 손동작을 50개 클래스 중 하나로
  분류. 응용: 근전 의수 제어, 재활, 제스처 인터페이스.

[1.2] 입력 명세
  · 물리 입력: 팔뚝 12전극 sEMG, 2kHz 샘플링.
  · 모델 입력(전처리 후): 텐서 shape (24, 600)
      - 24채널 = 원신호 12채널 + 포락선 12채널
      - 600샘플 = 300ms 윈도우 (2kHz)
  · 보조 입력: 피험자 ID(정수) — 피험자 임베딩 조회용.

[1.3] 출력 명세
  · 50차원 로짓 → softmax → 50 클래스 확률.
  · 최종 예측 = argmax (또는 앙상블 확률 평균의 argmax).
  · 클래스: 49개 손동작 + 무동작(rest). rest 포함.

[1.4] 평가 단위 (2종)
  · 프레임(per-frame): 윈도우 1개당 예측 1개. 실시간에 대응, 최엄격.
  · 동작 단위(per-movement): 한 제스처 실행의 연속 윈도우를 다수결로 1개 답.
    Ninapro 문헌 표준. 경계 순간 오류가 상쇄됨.

2. 데이터 명세 (Ninapro DB2 · 분할)
================================================================================

[2.1] 데이터셋
  · Ninapro DB2: 근전도 제스처 인식 공개 벤치마크.
  · 40명(피험자), 각자 50 손동작(rest 포함)을 6회 반복 수행.
  · 12전극 sEMG, 2kHz.

[2.2] 분할 (subject-dependent / intra-subject)
  · Train = 반복(repetition) 1~4
  · Validation = 반복 5
  · Test = 반복 6 (학습·검증에 전혀 미사용, 홀드아웃)
  · 같은 40명이 모든 분할에 등장(다른 회차). 즉 테스트 피험자는 학습에서 이미
    본 사람 → 피험자 임베딩 사용 가능. (새 사용자는 [7] 등록 필요.)

[2.3] 전처리 후 규모 (전처리전달_v28)
  · 학습 윈도우 약 447,047개. 각 (24×600) float32.
  · 클래스 불균형: 무동작(rest)이 윈도우의 약 44%.
  · hard subject 5명 = {S4, S7, S26, S28, S31} (낮은 SNR, 동작 간 구분 작음).

3. 전처리 파이프라인 (단계별 정확 파라미터)
================================================================================

원신호(12채널, 2kHz)에서 모델 입력(24채널 × 600샘플 윈도우)까지:

  [단계 1] 대역통과 필터 20~500Hz
      · 근전 유효 대역만 통과. 저주파 드리프트·고주파 잡음 제거.
  [단계 2] 노치 필터 50Hz
      · 전원(콘센트) 유래 50Hz 간섭 제거.
  [단계 3] 피험자별 정규화
      · 12채널 원신호 EMG를 피험자별 통계(학습 반복의 연속 신호 기준)로 표준화.
      · 사람마다 다른 신호 세기 스케일 정합. (norm_mean.npy / norm_std.npy 저장.)
  [단계 4] 포락선 추출
      · 정규화된 EMG의 절댓값 → 10Hz 4차 저역통과 → 근육 활성 세기 포락선 12채널.
  [단계 5] 24채널 스택
      · 원신호(정규화) 12채널 + 포락선 12채널 = 24채널.
      · 채널 인덱스 규약: i(0~11)=원신호 전극 i, i+12=전극 i의 포락선.
        (→ [9] 채널 드롭아웃에서 전극 i 제거 = 채널 i와 i+12 동시 0.)
  [단계 6] 윈도우링
      · 창 길이 300ms(600샘플), stride 150ms(300샘플, 50% 중첩).
  [단계 7] 순도(purity) 필터
      · 한 창에서 지배 라벨 비율 ≥0.8인 창만 사용(경계 잡음 통제).

  산출: 각 표본 = (24, 600) 윈도우 + 피험자 ID + 동작 라벨.

[3.8] 각 전처리 선택의 신호처리 근거 (왜 이 값인가)
  · 대역통과 20~500Hz: 표면 근전 신호의 유효 에너지는 대략 20~450Hz에 집중된다.
    20Hz 미만은 움직임 아티팩트·기저선 드리프트(전극-피부 임피던스 변화)라 제거하고,
    500Hz 초과는 주로 열잡음·고주파 간섭이라 잘라낸다. 4차 Butterworth류가 통례.
  · 노치 50Hz: 상용 전원(한국 60Hz가 아닌 DB2 수집지 기준 50Hz) 및 그 근방
    간섭을 좁게 제거. 근전 정보 손실을 최소화하기 위해 폭이 좁은 노치를 쓴다.
  · 피험자별 정규화: 전극 접촉·피하지방·근육량 차이로 사람마다 절대 진폭이 크게
    다르다. 정규화 없이 넣으면 진폭 큰 사람·채널이 학습을 지배한다. 학습 반복의
    연속 신호 통계(평균·표준편차)로 표준화해 분포를 정렬한다. (배포 시 새 사용자는
    자신의 통계로 재정규화 — 게인 드리프트 완화와도 연결.)
  · 포락선(정류+10Hz 저역통과): 원신호는 부호가 빠르게 진동해 "언제·얼마나 세게
    수축하는가"의 저주파 포락 정보가 표면에 드러나지 않는다. 절댓값(정류) 후 10Hz
    저역통과로 근육 활성 세기의 매끄러운 포락선을 얻어, 원신호(빠른 패턴)와 상보적인
    느린 세기 채널을 추가한다.
  · 윈도우 300ms: 근전 제어 문헌의 통상 최적 구간. 너무 짧으면(≤100ms) 통계·주파수
    추정이 불안정하고, 너무 길면(≥400ms) 실시간 지연이 커지고 한 창에 두 동작이
    섞일 위험이 커진다. 300ms는 정확도-지연 절충점.
  · stride 150ms(50% 중첩): 창을 겹쳐 잘라 학습 표본 수를 늘리고 경계 근처 시간
    해상도를 확보한다.
  · 순도 ≥0.8: 제스처 시작·끝 전이 구간은 라벨이 섞여 잡음이 크다. 한 창의 지배
    라벨 비율이 80% 이상인 창만 남겨 라벨 잡음을 통제(단, 이 전이 구간이 프레임
    성능을 깎는 근본 원인이라 시간 후처리로 별도 회복 — [10] 참조).

4. 기반 아키텍처 상세 (레이어별)
================================================================================

주 모델 클래스: SubjectAwareCNNLSTMAttention (code/models_v8.py, 약 805K 파라미터)
입력: x (B, 24, 600), subject_idx (B,)

[4.1] 피험자 임베딩
  · nn.Embedding(n_subjects+1, 32)
  · subject_idx → (B, 32) 벡터. 사람별 신호 경향을 학습해 개인차에 적응.
  · 설계 근거: 개인 정보를 "제거"(도메인 적응/DANN)하지 않고 "활용". EMG에선
    피험자 정보가 분류에 유용한 단서.

[4.2] CNN 특징 추출기 (self.cnn)
  · Conv1d(24 → 64, kernel=5, padding=2) → BatchNorm1d(64) → ELU → MaxPool1d(2)
  · Conv1d(64 → 128, kernel=3, padding=1) → BatchNorm1d(128) → ELU → MaxPool1d(2)
  · 출력: (B, 128, 150)  — 시간 길이 600 → 150으로 축약, 국소 패턴 추출.

[4.3] 시퀀스 결합
  · CNN 출력을 (B, 150, 128)로 transpose.
  · 피험자 임베딩(32)을 각 시점에 확장·concat → (B, 150, 160).

[4.4] BiLSTM (self.lstm)
  · nn.LSTM(input=160, hidden=128, num_layers=2, batch_first=True, bidirectional=True)
  · 출력: (B, 150, 256) — 양방향(128×2). 시간 순서 패턴 학습.

[4.5] Attention (self.attention)
  · Linear(256 → 256) → Tanh → Linear(256 → 1) → softmax(시간축)
  · 가중합 → context (B, 256). 300ms 내 중요 시점 강조.

[4.6] 분류 헤드 (self.fc)
  · Dropout(0.4) → Linear(256 → 50) → 50 로짓.

  전체 흐름: x → CNN → (+subject emb) → BiLSTM → Attention → FC → 50 로짓.

[4.7] 차원 흐름 (배치 B 기준, 예: B=256)
  입력            x            (B, 24, 600)     subject_idx (B,)
  Conv1d(24→64,k5,p2)          (B, 64, 600)     시간 길이 보존(padding)
  BN+ELU+MaxPool(2)            (B, 64, 300)     시간 1/2 축소
  Conv1d(64→128,k3,p1)         (B, 128, 300)
  BN+ELU+MaxPool(2)            (B, 128, 150)    시간 다시 1/2 → 최종 150 스텝
  transpose                    (B, 150, 128)
  subject_emb 확장·concat      (B, 150, 160)    각 시점에 32차원 임베딩 부착
  BiLSTM(160→128, 2층, 양방향) (B, 150, 256)    128×2(양방향)
  Attention(256→가중합)        (B, 256)         150 시점을 1개 context로 요약
  Dropout(0.4)+Linear(256→50)  (B, 50)          로짓

[4.8] 파라미터 수 개략 분해 (기반 v8, 약 805K)
  · subject_emb: (40+1)×32 ≈ 1.3K
  · conv1: 24×64×5 + 64 ≈ 7.7K   · conv2: 64×128×3 + 128 ≈ 24.7K   · BN 소량
  · BiLSTM: 입력160·은닉128·2층·양방향 → 대부분의 파라미터(≈700K대) 차지
  · attention: 256×256 + 256 + 256 ≈ 66K
  · fc: 256×50 + 50 ≈ 12.8K
  → LSTM이 용량의 대부분. (용량 확대가 성능을 못 올린 것은 병목이 용량이 아니라
    정보·구조였음을 시사 — 상세요약 참조.)

[4.9] 설계 근거
  · 커널 5 → 3: 첫 층은 넓은 커널(5)로 저수준 파형 모양을, 둘째 층은 좁은 커널(3)로
    조합 패턴을 잡는다. MaxPool 2회로 유효 수용영역을 넓히며 시간 600→150 축소.
  · 양방향 LSTM: 300ms 창 내에서 앞뒤 문맥을 모두 보면 동작 전개(수축→유지→이완)를
    더 잘 잡는다. (실시간 스트리밍은 창 단위 독립 분류라 창 내 양방향은 허용.)
  · Attention: 창 내 모든 시점이 동등 정보량은 아니다(동작 정점이 정보 밀도 높음).
    가중합으로 중요한 시점을 강조해 요약 벡터의 판별력을 높인다.

5. 멤버 아키텍처 변형 (v8 / v44 / v45 / v41)
================================================================================

앙상블은 아래 4종 아키텍처(및 재현 시드)로 구성. 모두 [4]의 기반을 공유하고
특징 분기·잔차만 다르다. 생성자 시그니처는 동일: (n_channels=24, n_classes=50,
n_subjects=40).

[5.1] v8 — 기반형 (models_v8.py)
  · [4] 그대로. 앙상블 멤버: v40, v38 (동일 아키텍처, 다른 학습 설정/시드).

[5.2] v44 — 시간영역 특징 결합형 (models_v44.py, SubjectAwareCNNLSTMAttentionFeat)
  · [4] 기반 + 수공 TD 특징 분기.
  · TD 특징(EMG 12채널에서 forward 내부 계산): RMS, MAV, WL(파형길이),
    ZC(영점교차), SSC(기울기부호변화) × 12채널 = 60차원.
  · BatchNorm(60)으로 스케일 정합 후 MLP → attention context와 결합해 분류.
  · 효과: hard subject 개선(+0.93p).

[5.3] v45 — 주파수영역 특징 결합형 (models_v45.py, SubjectAwareCNNLSTMAttentionFeatFD)
  · [4] 기반 + 수공 FD 특징 분기.
  · FD 특징: MNF(평균주파수), MDF(중앙주파수), PKF(피크주파수) × 12 = 36차원.
  · BatchNorm(36) 후 결합. 효과: easy subject 개선(+0.15p), 근피로 정보 반영.

[5.4] v41 — 잔차 CNN형 (models_v41.py, SubjectAwareResCNNLSTMAttention)
  · [4]의 CNN에 잔차(residual) 연결 추가(약 1.8배 파라미터).
  · 단독 성능은 기반형과 유사하나 앙상블 다양성 멤버로 기여.

[5.5] 수공 특징 정의식 (채널 c의 신호 x_c[t], 길이 T)
  [시간영역 TD — v44]
   · RMS_c  = sqrt( (1/T) Σ_t x_c[t]^2 )            신호 크기 대표값(근수축 세기)
   · MAV_c  = (1/T) Σ_t |x_c[t]|                     평균 절대 진폭
   · WL_c   = Σ_t |x_c[t+1] − x_c[t]|                파형 길이(누적 변화량·복잡도)
   · ZC_c   = Σ_t 1[ x_c[t]·x_c[t+1] < 0 , |Δ|>ε ]  영점 교차 수(주파수 대용)
   · SSC_c  = Σ_t 1[ 기울기 부호 변화 , |Δ|>ε ]      기울기 부호 변화 수(활동성)
   → 채널 12개 × 5특징 = 60차원. ε는 잡음 무시용 임계.
  [주파수영역 FD — v45]  (파워 스펙트럼 P(f))
   · MNF_c  = Σ_f f·P(f) / Σ_f P(f)                  평균 주파수(근피로 시 하강)
   · MDF_c  = P(f)의 누적 파워가 절반이 되는 주파수    중앙 주파수
   · PKF_c  = argmax_f P(f)                           피크 주파수
   → 채널 12개 × 3특징 = 36차원.
  모두 forward 내부에서 (정규화된) EMG 채널로부터 계산되고, BatchNorm으로 스케일을
  맞춘 뒤 MLP를 거쳐 attention context와 결합된다. TD는 세기·복잡도를, FD는 스펙트럼
  이동(피로·수축형태)을 포착해 상보적이다.

6. 학습 방법 (증강 · 손실 · 최적화)
================================================================================

모든 멤버는 동일 "v40 레시피"로 학습(pooled, 40명 통합). code/train_cnn_v40.py 기준.

[6.1] 데이터 증강 (GPU 온라인, 매 배치)
  라벨 의미를 보존하는 증강만 사용(전극 shift 등 라벨 파괴 증강은 배제).
  · jitter:          p=0.5, σ=0.06 (가우시안 잡음 가산)
  · magnitude warp:  p=0.5, σ=0.30, knots=4 (채널쌍별 부드러운 크기 왜곡)
  · time warp:       p=0.5, σ=0.25, knots=4 (시간축 부드러운 왜곡, grid_sample)
  · mixup:           p=0.5, α=0.30 (두 표본·라벨 선형 혼합)

[6.2] 손실 함수 — Focal Loss
  · γ=2.0. 맞히기 쉬운 표본(특히 rest)의 손실 비중을 낮추고 어려운 표본에 집중.
  · mixup 적용 시 두 타깃에 대해 λ 가중 합산.

[6.4] 증강 정의식 (배치 x, 채널 C, 시간 T)
  · jitter:          x' = x + ε,  ε ~ N(0, σ²),  σ=0.06
                     의미: 소량 센서 잡음 모사. 잡음 강건성의 근원([13.1]).
  · magnitude warp:  x'[c,t] = x[c,t]·g[c,t]
                     g = knots(=4개, N(1,σ²), σ=0.30)를 시간축으로 부드럽게 보간한
                     곡선. 원신호·포락선 채널쌍에 같은 곡선 적용(라벨 보존).
  · time warp:       누적 속도 곡선 s(t)=cumsum(exp(N(0,σ²)))를 [0,1]로 정규화해
                     grid_sample로 시간축 재표집. 동작 속도 변이 모사(σ=0.25).
  · mixup:           x' = λ·x_i + (1−λ)·x_j,  라벨도 λ 가중,  λ ~ Beta(α,α), α=0.30
                     결정경계를 매끄럽게 하고 과적합을 억제.
  ★ 원칙: 위 증강은 모두 "같은 동작의 그럴듯한 변형"이라 라벨 의미를 보존한다.
    (전극 shift처럼 전극 아래 근육이 바뀌어 라벨-신호가 어긋나는 증강은 배제.)

[6.5] Focal Loss 정의식
  · p_t = 정답 클래스의 예측 확률.
  · FL(p_t) = −(1 − p_t)^γ · log(p_t),  γ=2.0
  · (1−p_t)^γ 항: 이미 잘 맞히는 표본(p_t→1)의 손실을 크게 줄여, 흔하고 쉬운
    rest에 학습이 쏠리는 것을 막고 어려운 표본에 집중. γ=0이면 표준 교차엔트로피.

[6.3] 최적화
  · Optimizer: AdamW, lr=1e-3, weight_decay=1e-4
  · Scheduler: CosineAnnealingLR, T_max=50, eta_min=1e-6
  · Epochs: 50, Early stopping patience=8
  · Batch size: 256
  · 모델 선택: validation macro-F1 최고 시점 체크포인트 저장.

7. 개인 적응 · 등록(enrollment)
================================================================================

[7.1] 피험자별 적응형 미세조정 (선택적, +0.3p)
  · 공통(pooled) 모델의 CNN을 동결하고 각 사용자 데이터로 상위부만 재학습.
  · 각 사용자 검증 성적으로 "개인화 vs 공통" 중 나은 쪽 자동 선택(adaptive).
  · hard/easy 라벨 불요 — 각자 데이터로만 결정.

[7.2] 등록(enrollment) — 새 사용자 사용 전 1회
  · 본 모델은 subject-dependent 프로토콜. 피험자 임베딩이 학습돼 있어야 함.
  · 새 사용자 절차:
      1) 사용자가 제스처 샘플(라벨 포함)을 수 회 수행 → 수집.
      2) 개인 임베딩 학습(또는 상위층 미세조정).
      3) 이후 재보정 없이 사용.
  · "균일"의 정확한 의미: 사용(추론) 중엔 개인 라벨·매 세션 재보정 불요. 단 최초
    1회 등록은 필요(실제 근전 의수의 캘리브레이션 관행과 동일).

[7.3] 등록 데이터 요구·비용
  · 필요: 새 사용자가 각 제스처를 몇 회 수행한 라벨된 샘플(DB2 기준 반복 1~4에
    해당). 안내형 세션으로 수 분 소요.
  · 절충: 반복 수가 많을수록 개인 임베딩·적응 품질이 오르나 사용자 부담이 커진다.
    최소 요구는 각 제스처 소수 반복이며, 부담이 큰 시나리오에선 반복을 줄이고
    공통(pooled) 성능(70%대)으로 시작할 수 있다.
  · 프라이버시: 등록 데이터는 개인 임베딩·적응에만 쓰이며 추론 중 추가 수집 없음.

[7.4] 개인 임베딩 학습 절차 (2가지)
  · 방식 A(경량): 전체 백본을 동결하고 그 사용자의 32차원 임베딩 벡터만 라벨된
    등록 데이터로 학습. 매우 빠르고 저장 부담 작음.
  · 방식 B(적응): CNN을 동결하고 상위층(LSTM/attention/fc)까지 미세조정. 방식 A보다
    개인화 폭이 크나 계산·과적합 위험이 소폭 증가. 검증 성적으로 A/B/공통 중 자동 선택.
  · 두 방식 모두 사용 중(추론)에는 추가 데이터·라벨을 요구하지 않는다.

8. 앙상블 구성 (champion 8멤버)

[8.1] 결합 방식
  · 각 멤버의 softmax 확률을 산술 평균 → argmax. 추론 전용, 재학습 0.

[8.2] champion 8멤버
  1. v44          (TD 특징, seed A)
  2. v44_rep1     (TD 특징, seed B)
  3. v44_rep2     (TD 특징, seed C)
  4. v45          (FD 특징, seed A)
  5. v45_rep2     (FD 특징, seed B)
  6. v40          (기반 v8)
  7. v41          (잔차 CNN)
  8. v38          (기반 v8, 다른 설정)

[8.3] 구성 원칙
  · 멤버는 "비상관(다양) + 충분한 강도" 둘 다 필요. 너무 약한 멤버(예: 스펙트로그램
    57%)는 이득 0.
  · 조합 robustness: 같은 크기의 어떤 조합이든 성능 spread ±0.2p → 특정 멤버에
    비의존.

[8.4] 앙상블이 작동하는 원리 (분산 감소)
  · 확률 평균은 각 멤버의 편향(bias)은 그대로 두되 분산(variance)을 줄인다.
  · M개 멤버의 오차가 서로 독립이면 앙상블 오차 분산은 대략 σ²/M로 감소한다.
    실제로는 멤버가 부분 상관되어 감소폭이 σ²/M와 σ² 사이에 놓인다.
  · 따라서 멤버는 (a) 개별적으로 충분히 강하고(편향이 작고) (b) 서로 다른 지점에서
    틀려야(오차 비상관) 이득이 크다. 우리 멤버는 아키텍처(v8/v44/v45/v41)·특징
    (없음/TD/FD)·시드가 달라 비상관성을 확보한다.
  · 반례: 단독 57%의 약한 다른-아키텍처(스펙트로그램) 멤버는 편향이 커서 평균을
    끌어내려 순이득 0. → "다양성엔 강도 하한"이 존재.

9. 강건 변형 (robust3 · 채널 드롭아웃)
================================================================================

[9.1] 동기
  기본 champion은 전극 1개 고장 시 −13.5p로 취약(24채널 전부를 신뢰하도록 학습).
  실사용(의수)에서 전극 이탈·고장은 흔하므로 강건 변형을 별도 제공.

[9.2] 채널 드롭아웃 증강
  · 훈련 중 매 배치, 각 전극을 독립 확률 q=0.10으로 0으로 만듦.
  · 전극 i 드롭 = 채널 i(원신호)와 i+12(포락선)를 동시에 0.
  · 평균 약 1.2개 전극이 매 표본에서 가려짐 → 특정 전극 과의존 제거.
  · 라벨 의미 보존(전극이 없는 "같은 동작")이라 안전.

[9.5] 채널 드롭아웃 기대값·원리
  · 전극 수 12, 드롭 확률 q=0.10, 독립 → 표본당 드롭 개수 ~ Binomial(12, 0.10).
    기대 1.2개, 대부분 0~3개. (전극 i 드롭 시 채널 i와 i+12를 함께 0.)
  · 효과: 어떤 단일 전극도 항상 존재한다고 가정할 수 없게 되어, 모델이 판별
    정보를 여러 전극에 분산 표현(redundancy)하도록 강제된다. 결과적으로 배포 시
    전극 1~2개가 실제로 빠져도 성능 저하가 작아진다([13.2]).
  · q를 너무 키우면(예: 0.3+) clean 정확도 손실이 커지고, 너무 작으면 강건성이
    약하다. q=0.10은 clean −1.0p로 큰 강건성을 얻는 절충값.

[9.3] robust3 구성
  · v40 레시피 + 채널드롭으로 재훈련한 3멤버:
      - v61: 기반 v8 채널드롭
      - v62: v44(TD) 채널드롭
      - v63: v45(FD) 채널드롭
  · 확률 평균으로 결합.

[9.4] 효과 (상세는 [13])
  · clean 프레임 72.0%(champion 대비 −1.0p)만 내주고, 전극 1개 고장에도 70.7%
    유지(champion 59.6%, +11.1p).

10. 시간 후처리 스테이지 (평활 · 분할 · 보정) — 선택
================================================================================

앙상블 프레임 예측 위에 얹는 선택적 스테이지. 배포 시나리오에 맞게 조합.

[10.1] 인과 평활 (causal smoothing) — 실시간
  · 피험자 시간순 확률 스트림의 과거만 사용하는 이동평균(W=5).
  · 프레임 73.0 → 74.7% (+1.7p). 지연 최소, 실시간 적합. (추론 파이프라인 내장.)

[10.2] 중심 평활 (centered smoothing) — 준실시간
  · 앞뒤 대칭 이동평균. 78.6% (1.5~3초 지연 허용 시).

[10.3] 실제 분할 (segmentation)
  · 예측된 rest/비rest 런으로 제스처 구간을 검출해 구간 다수결. 80.4%(정직한
    동작단위, 경계를 스스로 검출).

[10.4] 학습된 시간 보정 (temporal corrector) — 오프라인
  · 앙상블 확률 스트림 위 경량 시퀀스 모델. per-movement 82.6%, hard 79.8%(최선).
  · 프레임은 과평활로 저하 → 오프라인·per-movement 전용.

[10.5] 동작단위 oracle[10.5x] 후처리 스테이지 메커니즘 상세
  · 인과 평활: 각 시점 t의 앙상블 확률을 과거 W개(현재 포함)의 이동평균으로 대체.
    미래를 안 보므로 실시간 가능. 순간적 rest-플립을 부드럽게 덮는다.
  · 중심 평활: t 앞뒤 대칭 창으로 평균 → 더 매끈하나 미래 대기(=지연) 필요.
  · 실제 분할: 예측 스트림에서 rest/비rest 런을 찾아 제스처 구간 경계를 추정하고,
    구간 내부만 다수결. gap-bridge(짧은 rest 삽입 무시)·min-length(너무 짧은 구간
    제거)로 경계 잡음을 정리.
  · 학습 시간보정: 위 손튜닝을 대체해 경량 LSTM이 확률 스트림에서 직접 시간 구조를
    학습. per-movement·hard에 최선이나 프레임은 과평활로 손해 → 오프라인 전용.

[10.5] 동작단위 oracle
  · 제스처 경계를 안다고 가정한 표준 다수결. 88.0%(문헌 비교용 상한).

[12.1] champion(8멤버) 대표 성능 — 신뢰구간 병기
  · 프레임    73.0%  95%CI [70.8, 75.3] (±1.1p) / macro-F1 0.644 / hard 63.1%
  · 동작단위  88.0%  95%CI [86.4, 89.6] (±0.8p) / macro-F1 0.846 / hard 83.9%
  · CI 산출: 피험자 40명 복원추출 부트스트랩 B=2000(피험자 간 일반화 변동 반영).
  · hard는 표본 5명이라 CI 넓음(동작단위 [77.0, 89.5]) → 반드시 CI와 병기.

[12.1b] 지표 정의식
  · 정확도 = (맞힌 표본 수) / (전체 표본 수).
  · 클래스 c의 정밀도 P_c = TP_c/(TP_c+FP_c), 재현율 R_c = TP_c/(TP_c+FN_c),
    F1_c = 2·P_c·R_c/(P_c+R_c).
  · macro-F1 = (1/50) Σ_c F1_c  — 50 클래스 동등 가중(불균형에 강건).
  · 동작 단위 축약 알고리즘(per-movement):
      1) 테스트 배열을 (subject, label) 키로 훑어 연속 동일 구간(=한 제스처 실행)을
         나눈다.  2) 각 구간의 프레임 예측을 다수결(np.bincount·argmax)해 1개 답으로.
      3) 이 인스턴스 단위로 정확도·macro-F1을 계산.

[12.2b] 부트스트랩 신뢰구간 절차 ([12.1의 CI 산출])
  1. 테스트 피험자 40명을 복원추출로 40명 재표집(같은 사람 중복 허용).
  2. 재표집된 피험자들의 프레임(또는 인스턴스)만 모아 지표 재계산.
  3. 1~2를 B=2000회 반복 → 지표의 분포.
  4. 2.5·97.5 백분위수 = 95% CI, 표준편차 = ±값.
  · 피험자 단위로 재표집하는 이유: 실제 불확실성의 주원인은 "새 피험자로의
    일반화 변동"이기 때문(윈도우 단위 재표집은 이를 과소평가).
  · hard CI가 넓은 이유: hard 피험자가 5명뿐이라 재표집 시 구성 변동이 크다.

[12.2] seed 안정성

부록 D. 계산 예제 (직관용)
================================================================================

[D.1] 차원 흐름 수치 예 (B=256)
  (256,24,600) →conv1→ (256,64,600) →pool→ (256,64,300) →conv2→ (256,128,300)
  →pool→ (256,128,150) →transpose→ (256,150,128) →(+emb32)→ (256,150,160)
  →BiLSTM→ (256,150,256) →attention→ (256,256) →fc→ (256,50).

[D.2] 동작 단위 다수결 예
  "주먹 쥐기" 5초 실행 → 0.15초 stride로 약 30개 프레임.
  프레임 예측: 주먹×22, rest×5, pinch×3.
   · 프레임 채점: 22/30 = 73.3% 맞음.
   · 동작 채점: 다수결 = "주먹"(22 최다) → 이 동작 정답(100%).
  → 시작·끝 전이의 순간 오류(rest/pinch)가 다수결로 상쇄되어 73%→88%로 오름.

[D.3] 앙상블 분산 감소 직관
  멤버 8개 오차가 완전 독립이면 분산 1/8로 감소(표준편차 1/√8≈0.35배). 실제로는
  부분 상관이라 그보다 작게 감소하지만, seed 분산 ±0.03p로 매우 안정한 것이 이를
  뒷받침.

[D.4] 채널 드롭 기대값 예
  12전극·q=0.10 → 표본당 드롭 개수 기대 12×0.10=1.2개. 즉 학습 내내 평균 약 1개
  전극이 가려진 상태를 보므로, 배포 시 전극 1개 고장이 "학습 중 흔히 본 상황"이 됨
  (robust3가 전극 1개 고장에 −1.3p만 저하하는 이유).(robust3가 전극 1개 고장에 −1.3p만 저하하는 이유).

[D.5] Focal Loss 수치 예 (γ=2)
  · 쉬운 표본 p_t=0.9: (1−0.9)^2=0.01 → 손실이 CE의 1% 수준으로 축소.
  · 어려운 표본 p_t=0.3: (1−0.3)^2=0.49 → 손실 거의 유지.
  → 흔하고 쉬운 rest의 기여를 눌러 어려운 동작에 학습이 집중된다.

[D.6] macro-F1이 정확도보다 낮은 이유(직관)
  · 정확도는 표본 수 가중이라 흔한 rest를 잘 맞히면 높게 나온다.
  · macro-F1은 50 클래스를 동등 가중하므로, 표본이 적은 희귀 제스처의 낮은 F1이
    그대로 반영돼 값이 낮아진다(프레임 0.644). 동작 단위로 보면 경계 오류가
    상쇄돼 0.846으로 상승.
